# 0016: Автомашины DB лавлах болон тогтмол сонголтыг ялгах

- Огноо: 2026-09-10
- Төлөв: Баталсан
- Үндэслэл: Хэрэглэгч 7 DB лавлах, 10 enum/const бүлэг болон лавлах хөтлөх саналыг баталсан
- Холбоотой баримт: [Лавлахын бүртгэл](../db/vehicle-reference-data.md), [Автомашины талбарууд](../features/vehicle-fields.md), [Monorepo](0001-use-monorepo.md)

## Нөхцөл байдал

Автомашины талбарууд болон бөглөх шаардлага батлагдсан. Admin-аас хөтлөх бодит лавлах өгөгдөл, програмын дүрэмтэй холбоотой тогтмол сонголтыг ялгах шаардлагатай.

## Харьцуулсан хувилбарууд

- Бүх сонголтыг DB лавлах болгох: admin-аас удирдахад уян хатан боловч програмын нөхцөл, төлөв шилжилттэй холбоотой дурын утга нэмэгдэх эрсдэлтэй.
- Бүх сонголтыг кодын тогтмол болгох: хяналттай боловч марк, загвар, салбар нэмэх бүрд код өөрчлөх шаардлагатай.
- DB лавлах болон enum/const-ыг ялгах: бодит лавлахыг admin-аас, тогтмол бүлгийг кодоор удирдана. Энэ хувилбарыг сонгосон.

## Шийдвэр

Марк, загвар, хувилбар, кузовын төрөл, өнгө, салбар/байршил, тоноглол гэсэн 7 төрлийн DB лавлах ашиглана. Гадна/салоны өнгө нэг лавлах ашиглах тул эдгээр нь 8 талбарт хамаарна. Нэмэх, нэр засах, идэвхгүй болгох боломжтой; ашиглагдаж байгаа лавлахыг шууд устгахгүй, өмнөх холбоосыг хадгална.

Түлш, хурдны хайрцаг, хөтлөгч, жолооны байрлал, шинэ/хуучин, валют, үнэ харуулах хэлбэр, борлуулалтын төлөв, ирэлтийн төлөв, нийтлэлийн төлөв гэсэн 10 бүлгийг enum/const болгоно. DB лавлах шиг admin-аас дурын утга нэмэхгүй. Дундын тогтмолууд `packages/core`-ийн үүрэгт хамаарна.

Талбарын ID-тай холбоос болон дүрмийн дэлгэрэнгүйг [лавлахын бүртгэл](../db/vehicle-reference-data.md)-д хөтөлнө.

## Үр дагавар

- Марк -> загвар -> хувилбар хамаарлыг хадгалж, нэрийг машин бүрд давтан гараар оруулахгүй.
- Тогтмол сонголт болон програмын нөхцөлтэй дүрмийг кодын өөрчлөлттэй хамт хянана.
- Анхны ангиллын шийдвэрт enum-ийн бүтэн утгуудыг тогтоогоогүй. 2026-09-10-ны дараагийн баталгаагаар автомашины 10 бүлгийн утга, утгын кодыг [лавлахын бүртгэлд](../db/vehicle-reference-data.md) баталсан. DB хадгалалтын төрөл, TypeScript enum/const-ийн хэлбэр болон бодит schema хэрэгжүүлэлт тусдаа үлдэнэ.
- Зөвхөн автомашины хүрээний ангиллыг баталсан; сэлбэг, дугуйн лавлахыг автоматаар тогтоохгүй. Өмнөх ADR болон tech spec task-ийн төлөвийг орлуулахгүй.
