# 0003: Drizzle ORM ашиглах

- Огноо: 2026-09-08
- Төлөв: Баталсан
- Үндэслэл: Хэрэглэгчийн DB framework-ийн сонголт
- Холбоотой баримт: [Өгөгдлийн сан](../db/README.md), [Monorepo](0001-use-monorepo.md)

## Нөхцөл байдал

Өгөгдлийн сантай ажиллах framework-ийн сонголтыг баримтжуулна.

## Харьцуулсан хувилбарууд

Хэрэглэгчийн сонголтыг бүртгэсэн. Бусад ORM-ийг энэ шийдвэрийн хүрээнд харьцуулж үнэлээгүй.

## Шийдвэр

Өгөгдлийн сантай ажиллахад Drizzle ORM ашиглана. Хэрэглэгчийн бичсэн `duzzle` нэрийг Drizzle ORM гэж ойлгон нэршлийг нэг мөр болгосон.

Энэ шийдвэр нь database engine, driver, ORM-ийн яг хувилбар болон schema-г тогтоохгүй.

## Үр дагавар

- Өгөгдлийн сантай ажиллах хэрэгжүүлэлт Drizzle ORM сонголтыг дагана.
- Schema, migration болон өгөгдлийн дүрмийг `docs/db/` дотор баримтжуулна.
- Database болон migration workflow-ийг [ADR 0005](0005-use-postgresql-and-drizzle-migrations.md)-аар тодорхойлсон. Driver, хэрэгслийн хувилбар болон ажиллуулах нарийвчилсан журмыг цаашид тогтооно.

## Нээлттэй асуултууд

- PostgreSQL-ийн хувилбар юу байх вэ?
- Schema болон migration файлууд monorepo-ийн аль хэсэгт байрлах вэ?
- Website болон admin backend-ийн DB хандалтын зааг ямар байх вэ?
- Drizzle ORM-ийн хувилбар, driver, Drizzle migration workflow-ийн хэрэгслийн хувилбар болон тохиргоо юу байх вэ?

## Нэмэлт шийдвэрийн түүх

- 2026-09-08: Хэрэглэгч Drizzle ORM нэршлийг баталж, PostgreSQL болон Drizzle migration workflow-ийг сонгосон. [ADR 0005](0005-use-postgresql-and-drizzle-migrations.md) нь анх нээлттэй үлдсэн database болон migration сонголтыг шийдвэрлэсэн; ORM сонголт хэвээр.
