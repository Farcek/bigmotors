# 0022: Бүтээгдэхүүний зургийг hard disk дээр хадгалах

- Огноо: 2026-09-10
- Төлөв: Хэсэгчлэн орлуулсан; metadata болон main/item холбоосыг [ADR 0029](0029-use-shared-files.md) шинэчилсэн. Disk хадгалалтын шийдвэр хэвээр.
- Холбоотой баримт: [Зургийн DB бүтэц](../db/product-images.md), [Products](../db/products-schema.md), [TASK-06](../../docs.task.md#task-06-storage-ба-upload-технологи)

## Нөхцөл байдал

Хэрэглэгч зураг upload хийж hard disk дээр хадгалах, зургийн бүртгэлийг `product_images` хүснэгтэд хөтлөхөөр шийдсэн. Эх файл өөрчлөхгүй, тоо/форматын хязгаар болон браузерын дэмжлэгийн шалгалтгүй байх шаардлага өмнө батлагдсан.

## Харьцуулсан хувилбарууд

- S3-compatible object storage: TASK-06-ын өмнөх санал; хэрэглэгч батлаагүй.
- Серверийн hard disk: хэрэглэгчийн сонголт; disk-ийн багтаамж, persistence болон backup-ийг deployment талд хариуцна.

## Шийдвэр

Эх файлыг hard disk дээр, зам болон metadata-г `product_images`-д хадгална. Binary файлыг PostgreSQL-д хадгалахгүй. Бүтээгдэхүүний зурагт тусдаа `media_files` хүснэгт шаардлагагүй.

`products.main_image_id`, `products.item_image_id` нь `product_images.id` рүү заана. Баганын нарийвчилсан бүтэц, FK/эзэмшлийн constraint болон устгах дүрмийг DB баримтад үргэлжлүүлэн батална.

S3 болон `sharp`-аар эх зургийг боловсруулах өмнөх саналыг энэ урсгалд хэрэглэхгүй. Upload сан, transport болон аюулгүй serve-ийн хэрэгжүүлэлт нээлттэй; зөвхөн зураг харагдах эсэхийг шалгахгүй гэдгээр дурын файл гүйцэтгэх, замаас гарах эсвэл эрхгүй хандах боломж нээхгүй.

## Үр дагавар

- Зураг хадгалах external object-storage үйлчилгээ шаардахгүй.
- Upload файлууд deployment/rebuild үед алдагдахгүй persistent байршилтай байх ёстой; container ашиглавал persistent volume төлөвлөнө. Яг хавтас болон тохиргооны key нээлттэй.
- DB backup дангаараа хангалтгүй; зурагтай нь нийцүүлсэн backup/restore арга хэрэгтэй.
- Олон server instance ашиглавал бүх instance ижил файлуудад хүрэх аргыг тусад нь шийднэ.
- Upload эрх, нийтлэгдээгүй файлын хамгаалалт, үүсгэсэн хадгалалтын нэр, аюулгүй serve болон тасарсан upload-ийн цэвэрлэгээг хэрэгжүүлэхийн өмнө нарийвчилна.

TASK-06 хэсэгчлэн батлагдсан; upload endpoint, disk тохиргоо, DB migration болон deployment хэрэгжээгүй.
