# 0008: Frontend хэсгүүдэд @tabler/icons-react ашиглах

- Огноо: 2026-09-08
- Төлөв: Баталсан
- Үндэслэл: Хэрэглэгчийн icon library-ийн сонголт
- Холбоотой баримт: [UI / UX](../ui/README.md), [Admin UI](0007-use-mantine-and-vite-for-sysop-app.md), [Public website](0002-use-nextjs-and-nodejs-24.md)

## Нөхцөл байдал

Public website болон admin frontend-ийн icon library-ийг нэг мөр тогтооно.

## Харьцуулсан хувилбарууд

Хэрэглэгч `@tabler/icons-react`-ийг сонгосон. Бусад icon library-ийг энэ шийдвэрийн хүрээнд харьцуулж үнэлээгүй.

## Шийдвэр

`sysop-app` болон `website` хоёул icon library болгон `@tabler/icons-react` ашиглана.

## Үр дагавар

- Хоёр frontend-ийн icon сонголт нэг санд тулгуурлана.
- Icon-ийн хэмжээ, өнгө болон хэрэглээний дүрмийг UI / UX загвар боловсруулах үед тодорхойлно.
- Package-ийн хувилбар болон dependency тохиргоог хэрэгжүүлэлтийн үед тогтооно. Одоогоор package суулгагдаагүй.
