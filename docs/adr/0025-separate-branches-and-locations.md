# 0025: Компанийн салбар ба бүтээгдэхүүний байршлыг салгах

- Огноо: 2026-09-10
- Төлөв: Баталсан
- Холбоотой: [Лавлахууд](../db/reference-tables.md), [Schema](../db/catalog-schema-proposal.md), [ADR 0023](0023-approve-catalog-schema.md)

## Нөхцөл байдал

Өмнө `branches`-ийг "салбар / байршил" гэж нэгтгэсэн. Хэрэглэгч салбар нь компанийн салбар, байршил нь тухайн бүтээгдэхүүн бодитоор байгаа газар болохыг тодруулсан.

## Хувилбарууд

- Нэг лавлах хэвээр байлгах: хоёр өөр утгыг хольж, бүтээгдэхүүний хөдөлгөөнөөр салбарын харьяаллыг өөрчилнө.
- Тусдаа `branches`, `locations` лавлах: компанийн салбар болон бүтээгдэхүүний бодит байршлыг бие даан бүртгэнэ. Энэ хувилбарыг хэрэглэнэ.

## Шийдвэр

- `branches` нь компанийн салбар; `locations` нь бүтээгдэхүүний бодит байршил. Хоёул автомашин, сэлбэг, дугуйд дундын.
- `vehicles`, `parts`, `tires`-ийн `branch_id` хэвээр, тус бүр nullable `location_id` -> `locations.id` нэмнэ. TypeScript нэр `branchId`, `locationId`.
- Байршил нь лавлахын нийтлэг 7 баганатай, нэр дотроо давхардахгүй, ашиглагдсан мөрийг FK RESTRICT хамгаална. Салбар болон байршил ижил нэртэй байж болно.
- Бэлэн (`in_stock`) машиныг нийтлэх/нийтэлсэн мэдээллийг засахад бодит байршил заавал. Өмнөх `branch_id` шаардлагыг `location_id` орлоно. Компанийн салбар сонголттой. Сэлбэг/дугуйн байршил сонголттой; шинэ заавал шаардлага нэмэхгүй.
- Байршлыг тодорхой салбарт заавал харьяалуулах дүрэм өгөөгүй тул лавлахуудын хооронд FK нэмэхгүй. Нэг бүтээгдэхүүн эхний хувилбарт нэг салбар, нэг одоогийн байршилтай. Олон байршлын үлдэгдэл, шилжилтийн түүх энэ өөрчлөлтөд орохгүй.

## Үр дагавар

Нийт 12 лавлах, каталогийн 23 хүснэгттэй болно. Шинэ migration нь өмнөх `branches`/`branch_id`-ийг хадгалж, байршлыг `NULL` үлдээнэ; салбараас байршил таахгүй, хуулбарлахгүй. Өмнө нийтлэгдсэн бэлэн машин байвал бодит байршлыг гараар оноох шаардлагатай; migration нийтлэлийг автоматаар нуухгүй. Байршил дутуу үед дараагийн нийтлэгдсэн мэдээллийн засвар шинэ дүрмээр хориглогдоно.

ADR 0016, 0017, 0018, 0023-ын салбар/байршлыг нэгтгэсэн хэсгийг энэ шийдвэр орлоно; бусад шийдвэр хэвээр. API/ACL/form integration нь тусдаа ажил; public сайт дээр бодит агуулахын байршлыг автоматаар нийтэд харуулахгүй, public field matrix-ийг тусад нь шийднэ.
