# 0004: Үндсэн хэрэглээний @napp сангуудыг ашиглах

- Огноо: 2026-09-08
- Төлөв: Баталсан
- Үндэслэл: Хэрэглэгчийн үндсэн сангийн сонголт
- Холбоотой баримт: [Monorepo бүтэц](0001-use-monorepo.md), [Төслийн README](../../README.md)

## Нөхцөл байдал

Төсөлд ашиглах үндсэн сангуудыг нэг мөр бүртгэж, хэрэгжүүлэлтийн үед баримтлах сонголтыг тогтооно.

## Харьцуулсан хувилбарууд

Хэрэглэгч дараах сангуудыг сонгосон. Бусад санг энэ шийдвэрийн хүрээнд харьцуулж үнэлээгүй.

## Шийдвэр

Үндсэн хэрэглээний сангууд:

- `@napp/error`: алдаа боловсруулах (error handling)
- `@napp/dti-core`
- `@napp/dti-server`
- `@napp/dti-client`

`sysop-dti` нь `sysop-server` болон `sysop-app` хоорондын API contract-ийг хариуцах төслийн package хэвээр байна. Дээрх сангуудыг monorepo-ийн аль package-д, ямар API-аар ашиглах нарийвчилсан зураглал хараахан тогтоогүй.

## Үр дагавар

- Хэрэгжүүлэлтийн үед дээрх сангуудын бодит API, dependency болон орчны шаардлагыг шалгаж ашиглана.
- Сан сонгогдсон нь dependency суулгасан эсвэл холболт хэрэгжсэн гэсэн үг биш.
- Алдааны код, API алдааны бүтэц болон хэрэглэгчид харуулах мэдээллийн дүрмийг contract боловсруулах үед тодорхойлно.

## Нээлттэй асуултууд

- Сан тус бүрийн хувилбар, registry болон суулгах тохиргоо юу байх вэ?
- `@napp/dti-*` сангуудыг `sysop-dti`, `sysop-server`, `sysop-app` болон бусад хэсэгт хэрхэн хуваарилах вэ?
- Алдаа боловсруулах нийтлэг дүрэм болон API error contract ямар байх вэ?
