# 0007: sysop-app-д Mantine болон Vite ашиглах

- Огноо: 2026-09-08
- Төлөв: Баталсан
- Үндэслэл: Хэрэглэгчийн admin frontend-ийн технологийн сонголт
- Холбоотой баримт: [Monorepo бүтэц](0001-use-monorepo.md), [TypeScript](0006-use-typescript-for-all-code.md), [UI / UX](../ui/README.md)

## Нөхцөл байдал

Admin frontend болох `sysop-app`-ийн UI сан болон build хэрэгслийг тогтооно.

## Харьцуулсан хувилбарууд

Хэрэглэгч Mantine болон Vite-ийг сонгосон. Бусад UI сан болон build хэрэгслийг энэ шийдвэрийн хүрээнд харьцуулж үнэлээгүй.

## Шийдвэр

- `sysop-app`-ийн UI library нь Mantine (`@mantine` сангууд) байна.
- `sysop-app`-ийн build хэрэгсэл нь Vite байна.
- Эх код болон UI компонентыг ADR 0006-ын дагуу TypeScript, TSX дээр бичнэ.
- Энэ сонголт нь `sysop-app`-д хамаарна. Public `website`-ийн Next.js болон PWA шийдвэр хэвээр байна.

## Үр дагавар

- Admin UI-ийн компонент болон theme-ийг Mantine-д тулгуурлан зохион байгуулна.
- Admin frontend-ийн хөгжүүлэлт болон build тохиргоог Vite-д нийцүүлнэ.
- Яг dependency, хувилбар болон ажиллуулах командыг хэрэгжүүлэлтийн үед тогтооно. Одоогоор сангууд суулгагдаагүй, build тохируулагдаагүй.

## Нээлттэй асуултууд

- Mantine болон Vite-ийн яг хувилбар, шаардлагатай `@mantine` package-ууд юу байх вэ?
- Admin-ийн routing болон theme-ийн нарийвчилсан тохиргоо ямар байх вэ?
