- Холбоотой баримт: [Monorepo бүтэц](0001-use-monorepo.md), [Agent-ийн заавар](../../AGENTS.md), [Төслийн README](../../README.md)

## Нөхцөл байдал

Monorepo-ийн бүх хэсэгт код бичих хэлийг нэг мөр тогтооно.

## Харьцуулсан хувилбарууд

Хэрэглэгч TypeScript-ийг сонгосон. Бусад хэлийг энэ шийдвэрийн хүрээнд харьцуулж үнэлээгүй.

## Шийдвэр

- Төслийн бүх эх кодыг TypeScript дээр бичнэ.
- Энэ шаардлага `website`, `sysop-server`, `sysop-app`, `sysop-dti`, `core` бүх хэсэгт хамаарна.
- API contract, shared helper, functions, Drizzle schema, seed болон төслийн script, тестийг мөн TypeScript дээр бичнэ.
- Эх кодын файлд `.ts`, JSX агуулсан компонентод `.tsx` өргөтгөл ашиглана.

Build-ээс үүсэх JavaScript, Drizzle workflow-оор үүсэх SQL migration болон JSON, YAML, Markdown зэрэг өгөгдөл, тохиргоо, баримтын формат нь эх кодын хэлний сонголтыг өөрчлөхгүй.

## Үр дагавар

- Package бүрийн build, тест болон type check тохиргоог TypeScript-д нийцүүлнэ.
- Төслийн гараар бичих код болон кодын жишээнд TypeScript-ийг баримтална.
- TypeScript хувилбар, `tsconfig` болон ажиллуулах script-ийг хэрэгжүүлэлтийн үед тодорхойлно. Энэ шийдвэр нь тэдгээрийг тохируулсан гэсэн үг биш.
