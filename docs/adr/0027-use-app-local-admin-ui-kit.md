# 0027: Admin UI kit-ийг app дотор нэгтгэх

- Огноо: 2026-09-12
- Төлөв: Баталсан
- Холбоотой баримт: [UI kit дүрэм](../ui/admin-ui-kit.md), [TASK-07](../../docs.task.md#task-07-frontend-хэрэгслүүд), [Mantine/Vite](0007-use-mantine-and-vite-for-sysop-app.md), [Tabler](0008-use-tabler-icons-react.md)

## Нөхцөл байдал

Sysop app-ийн routing болон UI demo бэлэн болсон. Дараагийн CRUD дэлгэцүүд нэг хэв маягтай байх, давхардсан style болон компонент үүсэхээс сэргийлэх дүрэм шаардлагатай.

## Харьцуулсан хувилбарууд

- Дэлгэц бүрд тусдаа компонент/style: эхэндээ хурдан боловч хэв маяг зөрөх, давхардал үүсэх эрсдэлтэй.
- Тусдаа `packages/uikit`: олон app ижил kit хэрэглэдэг үед хэрэгтэй; одоогоор нэг admin-д package/build-ийн нэмэлт зааг шаардлагагүй.
- App доторх shared UI: Mantine-ийг шууд ашиглаж, зөвхөн давтагдсан нийлмэл хэсгийг нэгтгэнэ.

## Шийдвэр

- Mantine болон Tabler-ийг үндсэн UI сан хэвээр ашиглаж, ижил зориулалтын сан давхар нэмэхгүй.
- Нийтлэг theme/token ашиглана. [UI kit дүрэм](../ui/admin-ui-kit.md) нь layout, өнгө/зай, form/list, үйлдэл, төлөв болон хүртээмжийн үндсэн баримт байна.
- Shared нийлмэл компонентын байршил `sysop/app/src/ui/`; тусдаа `packages/uikit` одоохондоо үүсгэхгүй.
- Mantine компонент бүрийг wrapper болгохгүй. API/DB логикийг shared UI-д оруулахгүй.
- Form/cache сангийн сонголтыг энэ шийдвэрт хамруулахгүй.

## Үр дагавар

- Шинэ admin дэлгэцүүд demo болон нийтлэг дүрэмд нийцнэ.
- Дүрэм, demo болон shared UI хэрэгжүүлэлтийг өөрчлөлтийн хүрээнд уялдуулан шинэчилнэ.
- Энэ нь баримтын баталгаа; шинэ компонент/package, dependency эсвэл бүх дэлгэцийн refactor хийх даалгавар биш.
- Public website-ийн UI kit болон app хооронд UI хуваалцах хэрэгцээг тусад нь шийднэ.
