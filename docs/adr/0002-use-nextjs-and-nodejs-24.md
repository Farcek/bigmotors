# 0002: Next.js болон Node.js 24 ашиглах

- Огноо: 2026-09-08
- Төлөв: Баталсан
- Үндэслэл: Хэрэглэгчийн технологийн сонголт
- Холбоотой баримт: [Monorepo](0001-use-monorepo.md), [PWA шаардлага](../features/pwa.md), [Ашиглалтын орчин](../operations/README.md)

## Нөхцөл байдал

Public website-ийн framework болон төслийн Node.js runtime-ийн үндсэн хувилбарыг тогтоох шаардлагатай.

## Харьцуулсан хувилбарууд

Хэрэглэгч Next.js болон Node.js 24-ийг сонгосон. Бусад framework болон runtime хувилбарыг энэ шийдвэрийн хүрээнд харьцуулж үнэлээгүй.

## Шийдвэр

- `website` хэсгийг Next.js дээр хийнэ.
- Public website нь PWA боломжтой байна. Нарийвчилсан хүрээг [PWA шаардлага](../features/pwa.md)-д хөтөлнө.
- Төслийн Node.js runtime нь 24.x байна.
- Энэ шийдвэрээр admin frontend болон backend-ийн framework-ийг тогтоогоогүй.

## Үр дагавар

- Хөгжүүлэлт, build, CI болон Node.js ашиглах серверийн орчныг 24.x хувилбарт нийцүүлнэ.
- Dependency сонгох үед сонгосон Next.js хувилбар болон Node.js 24-тэй нийцлийг шалгана.
- PWA-ийн хэрэгжүүлэлт, шинэчлэлт болон сүлжээ тасарсан үеийн үйлдлийг тусад нь тодорхойлох шаардлагатай.

## Нээлттэй асуултууд

- Next.js-ийн яг хувилбар, Node.js 24.11.0 буюу түүнээс дээших 24.x хувилбаруудаас алийг тогтоож ашиглах вэ?
- PWA хэрэгжүүлэх арга, дэмжих browser болон төхөөрөмжийн хүрээ ямар байх вэ?

## Нэмэлт шийдвэрийн түүх

- 2026-09-08: [ADR 0009](0009-use-tsdown-for-shared-libraries.md)-аар tsdown сонгож, Node.js 24.x-ийн доод хязгаарыг 24.11.0 (`>=24.11.0 <25`) болгосон. Node.js-ийн үндсэн хувилбар болон Next.js сонголт хэвээр.
