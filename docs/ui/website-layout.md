# Website-ийн суурь layout

- Баталсан: 2026-09-12.
- Styling: Tailwind CSS utility class. [ADR 0033](../adr/0033-use-tailwind-for-website.md).
- Website-ийн нийт хүрээ `width: 100%`, `max-width: 1440px`, `margin-inline: auto` байна. Header, main, footer нэг хүрээнд багтана.
- 1440px-ээс өргөн дэлгэц дээр хоёр талын гадна зай тэнцүү. Жижиг дэлгэц дээр viewport-оос хэтрэхгүй.
- Доторх хэвтээ зай: mobile 16px, `sm`-ээс 24px, `lg`-ээс 32px. Эдгээр зай 1440px хүрээн дотроо тооцогдоно.
- Нийтлэг хүрээг `web/website/src/app/layout.tsx` эзэмшинэ. Хуудас бүр дахин гадна container үүсгэхгүй.
- Custom CSS аль болох бичихгүй; utility class болон Tailwind theme token ашиглана. `globals.css` нь font import, Tailwind import болон `@theme` token-уудыг агуулна. Гадаад font-ийн `@import`-ийг Tailwind import-оос өмнө байрлуулна.
- Website-ийн эцсийн palette, typography, каталогийн дэлгэцийн дизайн тусдаа шийдэгдэнэ. Одоогийн нүүр нь суурь хуудас; бүтээгдэхүүний өгөгдөл хараахан холбоогүй.

## Theme ашиглах дүрэм

Баталсан: 2026-09-13. Зөвхөн public website-д хамаарна.

- Өнгөний нийтлэг утгыг Tailwind theme token-оор нэг газар тодорхойлно. Component бүр дээр HEX өнгө давтаж бичихгүй; зориулалтаар нэрлэсэн token-ийн utility class ашиглана.
- Үндсэн font болон текстийн өнгийг `body` дээр тохируулж, component-ууд удамшуулан хэрэглэнэ. Тусгай зориулалттай текстэд шаардлагатай override хийж болно.
- Primary өнгийг товч болон онцлох хэсэгт ашиглана; бүх текстийн үндсэн өнгө болгохгүй.
- Нэг theme ашиглана. Light/dark тусдаа theme, theme switch болон системийн өнгөний горимоор theme солих ажиллагаа нэмэхгүй. Нэмэлт CSS library хэрэггүй.

Энэ дүрэм нь тодорхой font сонголт, font сонгох шалгуур эсвэл palette-ийн бодит өнгөний утгыг батлахгүй. Өмнөх саналын font сонгох заалтыг оруулаагүй. Theme-ийн кодын хэрэгжүүлэлт тусдаа; одоогийн өнгө, font-ыг энэ баримтын өөрчлөлтөөр солихгүй.

## Header

- Баталсан бүтэц: зүүн талд logo; баруун талд search, menu. Notification, user товч нэмэхгүй.
- Нийт өндөр бүх дэлгэц дээр 143px, үндсэн хүрээний 1440px дотор байрлана.
- Header хар фон (`#1b1b1b`), logo болон icon-ийн өнгийг хэрэглэгчийн SVG asset-аас авна.
- `xl` буюу 1280px-ээс хэвтээ зай 120px; бага дэлгэц дээр 16/24/32px. Энэ нь header-ийн тусгай зай, main/footer-ийн дүрмийг өөрчлөхгүй.
- Компонент: `web/website/src/components/header/index.tsx`. Хэрэглэгчийн байршуулсан `logo.svg`, `icon.search.svg`, `icon.menu.svg`-ийг нэг хавтаснаас static import хийж ашиглана; SVG файлыг өөрчлөхгүй.
- Logo-ийн үндсэн хэмжээ 370.616 x 53.85px; жижиг дэлгэц дээр харьцаагаа хадгалан багасна.
- Header дээр өгсөн SVG icon-уудыг ашиглана. Бусад UI-ийн Tabler сонголт хэвээр. Товч 44px-ээс багагүй, tooltip болон accessible нэртэй байна.
- Хайлт товч доорх хайлтын overlay, цэс товч static menu overlay-г нээнэ.

### Header Search

- `src/components/header/search.tsx`: дээд хэсэгт бараан panel, logo/хаах товч, цагаан хайлтын form; арын хуудсыг тунгалаг бараан overlay бүрхэнэ.
- `HomeSearcher`-ийн `basicOnly` хувилбараар марк, загвар, гүйлтийн доод/дээд, хөдөлгүүрийн доод/дээд утга, хайх товчийг ашиглана. Desktop нэг мөр, tablet хоёр, mobile нэг багана. Дэлгэрэнгүй болон цэвэрлэх мөрийг энд харуулахгүй.
- Нээхэд `/api/vehicles/lookups`-аас нийтэд харагдах идэвхтэй лавлахуудыг авна. Ачааллын төлөв, дахин оролдох боломжтой алдааг харуулна. Марк өөрчлөхөд загвар цэвэрлэгдэнэ.
- Shared `VehicleSearchParams` validation болон URL helper ашиглан `/vehicles?...` рүү шилжинэ. Нүүр хуудасны дотроо үр дүн шинэчилдэг `HomeSearch` урсгалыг өөрчлөхгүй. `/vehicles`-ийн үр дүнгийн дэлгэц одоогоор хоосон route хэвээр.
- Цэс болон хайлт нь нийтлэг `header/overlay.tsx` ашиглана: scroll түгжих, scrollbar-ийн зай нөхөх, logo-ийн тогтвортой байрлал, focus, Escape болон гадна дараад хаах ажиллагаа ижил.

### Header Menu

- `src/components/header/menu.tsx`: бүтэн viewport бүрхсэн бараан тунгалаг overlay, дээд талд logo/хаах товч, desktop дээр баруун талд 320px өргөн цэс. Mobile дээр боломжит бүтэн өргөнөөр харагдаж, өндөр багатай үед цэс өөрөө scroll хийнэ.
- Нүүр, автомашин, сэлбэг, дугуй, footer-ийн танилцуулга/хаяг гэсэн static холбоосууд. Компанийн текст болон хаягийг footer-тэй нийтлэг `company-info.ts`-ээс авна. CMS/API холболт байхгүй.
- Native `dialog.showModal()` ашиглаж арын хуудасны харилцан үйлдлийг хаана, keyboard focus-ийг modal дотор барина. Арын scroll түгжиж, хаахад өмнөх style-уудыг сэргээнэ.
- Scroll түгжих үед scrollbar-ийн өргөнийг page болон overlay дээр нөхөж, төвлөрсөн хүрээг хөдөлгөхгүй. Overlay-ийн logo нь header-тэй ижил gap болон товчнуудын зайг хадгална; mobile дээр ч байрлал, хэмжээ өөрчлөгдөхгүй. Өндөр багатай үед зөвхөн цэсний агуулга scroll хийнэ.
- Хаах товч, Escape, цэсний гаднах хоосон хэсэг болон холбоос дээр дарахад хаагдана. Хаасны дараа focus цэс нээсэн товч руу буцна.
- Tabler icon, Tailwind theme token хэрэглэнэ. Бодит бус үйлчилгээ/мэдээний route, баталгаагүй утас/имэйл болон компанийн туршлагын тоо нэмэхгүй.

## Footer

- `src/components/footer/index.tsx`: бүх public хуудсанд root layout-аас ашиглах static footer. DB/API, CMS тохиргоо шаардахгүй.
- Хар section theme, нийтлэг `BodyContainer`; desktop дөрөв, mobile хоёр багана, 360px-ээс бага өргөнд нэг багана.
- Каталог, автомашины төлөв, түлшний төрөл, компани гэсэн дөрвөн цэстэй. Каталогийн холбоосууд одоогийн route-уудыг ашиглана; автомашины нөхцөлийг shared URL helper-ээр дамжуулна. Бидний тухай/хаяг нь footer доторх anchor.
- Доод хэсэгт BigMotors LLC, тусгаарлах шугам, хэрэглэгчийн өгсөн БЗД 16-р хорооллын хаяг болон давхардлыг арилгасан танилцуулгыг харуулна.
- Бодит утас, имэйл, сошиал URL батлагдаагүй тул дизайны placeholder мэдээллээр холбоос үүсгэхгүй.
