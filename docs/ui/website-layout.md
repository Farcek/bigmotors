# Website-ийн суурь layout

- Баталсан: 2026-09-12.
- Styling: Tailwind CSS utility class. [ADR 0033](../adr/0033-use-tailwind-for-website.md).
- Website-ийн нийт хүрээ `width: 100%`, `max-width: 1440px`, `margin-inline: auto` байна. Header, main, footer нэг хүрээнд багтана.
- 1440px-ээс өргөн дэлгэц дээр хоёр талын гадна зай тэнцүү. Жижиг дэлгэц дээр viewport-оос хэтрэхгүй.
- Доторх хэвтээ зай: mobile 16px, `sm`-ээс 24px, `lg`-ээс 32px. Эдгээр зай 1440px хүрээн дотроо тооцогдоно.
- Нийтлэг хүрээг `web/website/src/app/layout.tsx` эзэмшинэ. Хуудас бүр дахин гадна container үүсгэхгүй.
- Custom CSS аль болох бичихгүй; utility class болон Tailwind theme token ашиглана. `globals.css` нь font import, Tailwind import болон `@theme` token-уудыг агуулна. Гадаад font-ийн `@import`-ийг Tailwind import-оос өмнө байрлуулна.
- Website-ийн эцсийн palette, typography, каталогийн дэлгэцийн дизайн тусдаа шийдэгдэнэ. Одоогийн нүүр нь суурь хуудас; бүтээгдэхүүний өгөгдөл хараахан холбоогүй.

## Theme ашиглах дүрэм

Баталсан: 2026-09-13. Зөвхөн public website-д хамаарна.

- Өнгөний нийтлэг утгыг Tailwind theme token-оор нэг газар тодорхойлно. Component бүр дээр HEX өнгө давтаж бичихгүй; зориулалтаар нэрлэсэн token-ийн utility class ашиглана.
- Үндсэн font болон текстийн өнгийг `body` дээр тохируулж, component-ууд удамшуулан хэрэглэнэ. Тусгай зориулалттай текстэд шаардлагатай override хийж болно.
- Primary өнгийг товч болон онцлох хэсэгт ашиглана; бүх текстийн үндсэн өнгө болгохгүй.
- Нэг theme ашиглана. Light/dark тусдаа theme, theme switch болон системийн өнгөний горимоор theme солих ажиллагаа нэмэхгүй. Нэмэлт CSS library хэрэггүй.

Энэ дүрэм нь тодорхой font сонголт, font сонгох шалгуур эсвэл palette-ийн бодит өнгөний утгыг батлахгүй. Өмнөх саналын font сонгох заалтыг оруулаагүй. Theme-ийн кодын хэрэгжүүлэлт тусдаа; одоогийн өнгө, font-ыг энэ баримтын өөрчлөлтөөр солихгүй.

## Header

- Баталсан бүтэц: зүүн талд logo; баруун талд search, menu. Notification, user товч нэмэхгүй.
- Нийт өндөр бүх дэлгэц дээр 143px, үндсэн хүрээний 1440px дотор байрлана.
- Header хар фон (`#1b1b1b`), logo болон icon-ийн өнгийг хэрэглэгчийн SVG asset-аас авна.
- `xl` буюу 1280px-ээс хэвтээ зай 120px; бага дэлгэц дээр 16/24/32px. Энэ нь header-ийн тусгай зай, main/footer-ийн дүрмийг өөрчлөхгүй.
- Компонент: `web/website/src/components/header/index.tsx`. Хэрэглэгчийн байршуулсан `logo.svg`, `icon.search.svg`, `icon.menu.svg`-ийг нэг хавтаснаас static import хийж ашиглана; SVG файлыг өөрчлөхгүй.
- Logo-ийн үндсэн хэмжээ 370.616 x 53.85px; жижиг дэлгэц дээр харьцаагаа хадгалан багасна.
- Header дээр өгсөн SVG icon-уудыг ашиглана. Бусад UI-ийн Tabler сонголт хэвээр. Товч 44px-ээс багагүй, tooltip болон accessible нэртэй байна.
- Хайлт товч доорх хайлтын overlay, цэс товч static menu overlay-г нээнэ.

### Header Search

- `src/components/header/search.tsx`: дээд хэсэгт бараан panel, logo/хаах товч, цагаан хайлтын form; арын хуудсыг тунгалаг бараан overlay бүрхэнэ.
- `HomeSearcher`-ийн `basicOnly` хувилбараар марк, загвар, гүйлтийн доод/дээд, хөдөлгүүрийн доод/дээд утга, хайх товчийг ашиглана. Desktop нэг мөр, tablet хоёр, mobile нэг багана. Дэлгэрэнгүй болон цэвэрлэх мөрийг энд харуулахгүй.
- Нээхэд `/api/vehicles/lookups`-аас нийтэд харагдах идэвхтэй лавлахуудыг авна. Ачааллын төлөв, дахин оролдох боломжтой алдааг харуулна. Марк өөрчлөхөд загвар цэвэрлэгдэнэ.
- Shared `VehicleSearchParams` validation болон URL helper ашиглан `/vehicles?...` рүү шилжинэ. Каталог URL-ийн шүүлтүүрээр бодит үр дүнг ачаална. Нүүр хуудасны дотроо үр дүн шинэчилдэг `HomeSearch` урсгалыг өөрчлөхгүй.
- Цэс болон хайлт нь нийтлэг `header/overlay.tsx` ашиглана: scroll түгжих, scrollbar-ийн зай нөхөх, logo-ийн тогтвортой байрлал, focus, Escape болон гадна дараад хаах ажиллагаа ижил.

### Header Menu

- `src/components/header/menu.tsx`: бүтэн viewport бүрхсэн бараан тунгалаг overlay, дээд талд logo/хаах товч, desktop дээр баруун талд 320px өргөн цэс. Mobile дээр боломжит бүтэн өргөнөөр харагдаж, өндөр багатай үед цэс өөрөө scroll хийнэ.
- Нүүр, автомашин, сэлбэг, дугуй, footer-ийн танилцуулга/хаяг гэсэн static холбоосууд. Компанийн текст болон хаягийг footer-тэй нийтлэг `company-info.ts`-ээс авна. CMS/API холболт байхгүй.
- Native `dialog.showModal()` ашиглаж арын хуудасны харилцан үйлдлийг хаана, keyboard focus-ийг modal дотор барина. Арын scroll түгжиж, хаахад өмнөх style-уудыг сэргээнэ.
- Scroll түгжих үед scrollbar-ийн өргөнийг page болон overlay дээр нөхөж, төвлөрсөн хүрээг хөдөлгөхгүй. Overlay-ийн logo нь header-тэй ижил gap болон товчнуудын зайг хадгална; mobile дээр ч байрлал, хэмжээ өөрчлөгдөхгүй. Өндөр багатай үед зөвхөн цэсний агуулга scroll хийнэ.
- Хаах товч, Escape, цэсний гаднах хоосон хэсэг болон холбоос дээр дарахад хаагдана. Хаасны дараа focus цэс нээсэн товч руу буцна.
- Tabler icon, Tailwind theme token хэрэглэнэ. Бодит бус үйлчилгээ/мэдээний route, баталгаагүй утас/имэйл болон компанийн туршлагын тоо нэмэхгүй.

## Vehicles Catalog

- Шүүлтүүрийн бүх сонголтын бүлэг нэг утга авна. `Бүгд` нь тухайн бүлгийн шүүлтгүй төлөв бөгөөд reset хийхэд буцна. Хөтлөгчийн FWD/RWD/AWD/4WD сонголтыг shared `DRIVETRAINS`-аас гаргана.

- Дээд гарчиг, автомашины тоо/тайлбар, `Жишээ өгөгдөл` тэмдэглэгээтэй header хэсэг харагдахгүй. Шүүлтүүр болон grid удирдлагаас эхэлнэ.

- `/vehicles`: `src/components/vehicles.preview/index.tsx` дахь каталог. Server page URL-ийн query, идэвхтэй лавлахууд, эхний үр дүнг уншина. Дараагийн өөрчлөлт `GET /api/vehicles/search`-ээр хуудас дотор шинэчлэгдэнэ. Сонголт/preset шууд, тоон input 400ms debounce-тай. Буруу утгатай үед хүсэлт явуулахгүй.
- Шүүлтүүр, `sort`, `page`, `page_size`, `columns` URL-д хадгалагдана. Refresh, Back/Forward утгуудыг сэргээнэ. Хуучин хүсэлт болон хүлээгдэж буй debounce цуцлагдана; хуучин хариу шинэ үр дүнг дарж солихгүй. Ачаалал, үр дүнгүй, алдаа/дахин оролдох төлөвтэй.
- Шүүлтүүрийн төлөв, input-ийн `name`/`value`, validation нь core-ийн `VehicleSearchParams` / `vehicleSearchParams`-тай ижил. UUID лавлах болон enum утгыг нэр/label-аас тусад нь хадгална. Түлшний 7, хурдны хайрцгийн 6, хөтлөгчийн 4 сонголтыг shared enum-ийн дарааллаар гаргана. Жолооны байрлал, гадна өнгийн control нэмэхгүй.
- Үнэ, он, гүйлтийн түргэн сонголт доод/дээд input-ийг хамт шинэчилнэ. Гараар оруулсан хүрээ таарвал preset сонгогдоно, custom хүрээтэй бол аль ч preset сонгогдохгүй. `Бүгд` хоёр хязгаарыг цэвэрлэнэ. `<` сонголтын дээд хязгаар заасан тооноос нэгээр бага, бусад хязгаар inclusive байна.
- Бүхэл тоо, зөвшөөрөгдөх хязгаар, доод/дээд дараалал, ирээдүйн оны алдааг талбарын доор харуулна; 0 нь хүчинтэй утга. URL-ийн буруу утгыг засаж болохоор хадгалж, давхардсан/танихгүй параметрт мэдэгдэл харуулна. Reset бүх бүлэг, шинэ/хуучин, эрэмбэ болон алдааны төлөвийг цэвэрлэнэ.
- Shared `vehicleListingQuery` нь `VehicleSearchParams` дээр listing-ийн хуудаслалт/эрэмбэ/баганын параметрүүдийг нэмнэ; `home_product_group` filter schema-г өөрчлөхгүй. `newest`, `price_asc`, `price_desc` эрэмбэ ажиллана. Ижил утганд ID-аар тогтвортой эрэмбэлнэ; «Үнэ асуух» машины нууц үнэ ил гарахгүй, үнийн эрэмбийн төгсгөлд байрлана.
- Үндсэн хэсэг цагаан, текст бараан; зүүн шүүлтүүр цайвар саарал, input цагаан, хүрээ саарал. Сонгосон төлөвийн текст/хүрээ нь цагаан суурь дээр уншигдах бараан ногоон `card-accent` ашиглана. Header, footer болон нүүр хуудасны өнгийг өөрчлөхгүй; theme switch нэмэхгүй.
- Зүүн талын шүүлтүүр: марк, загвар, төрөл, үнэ, он, түлш, хурдны хайрцаг, гүйлт, хөдөлгүүр. Өндрийн хязгаар, тусдаа scroll болон sticky байхгүй; хуудастайгаа хамт scroll хийнэ. Mobile дээр дэлгэж/хураана. Гарчгийн дээр breadcrumb мөр харуулахгүй.
- Цагаан card-уудыг нимгэн саарал хүрээгээр ялгана. Нийтлэг grid сонгогч нь байрласан хэсгийн текстийн өнгийг удамшуулж, нүүр хуудасны бараан суурь болон каталогийн цагаан суурь дээр ажиллана.
- Баруун талд төлөв, эрэмбэ, бодит `CarCardItem` болон хуудаслалт байна. Зургийг `/files/:id/:originalName` URL-аар харуулна. Зөвхөн published + available автомашин гарна.
- Эрэмбэлэхийн өмнө нийтлэг `GridColumnControl`: `lg` (1024px)-ээс 2/3/4/6 багана, анхны утга 3. Нэг хуудсыг 6 мөрөөр тооцож 12/18/24/36 машин ачаална. `lg`-ээс доош үргэлж 24 машин. Breakpoint эсвэл баганын тооноос page size өөрчлөгдвөл 1-р хуудас руу буцна. SSR viewport мэдэхгүй тул URL-д size байхгүй бол 24-өөр эхэлж, client desktop хэмжээнд тааруулна.
- Desktop үзүүлэлтийн дээд тоо 4/3/2/0; 6 баганад badge нуугдана. Mobile 4 хүртэл үзүүлэлт, badge харуулна. Хуудаслалтад 3 хуудасны хязгаар байхгүй; хэтэрсэн page-г бодит сүүлийн хуудас руу тааруулна. Нүүрийн `/api/vehicles` нь 12 машин, дээд тал нь 3 хуудас гэсэн өмнөх дүрмээ хадгална.
- Маркын текст хайлт лавлах жагсаалтыг локалаар шүүнэ. Марк өөрчлөхөд загвар/хувилбар, загвар өөрчлөхөд хувилбар цэвэрлэгдэнэ. URL-д зөвхөн танигдсан загвар/хувилбар ирвэл эцгийг нөхнө; зөрүүтэй эцэг өгсөн бол алдаа харуулна. Лавлахад байхгүй URL сонголтыг fallback label-тай хадгална. Маркийн тоо бусад шүүлтүүрийг баримталж, марк/загвар/хувилбарын шүүлтүүрийг хасаж тоологдоно.

## Vehicle Detail

- `/vehicles/:id`: `src/components/vehicle.detail` нь бодит автомашины өгөгдөлтэй. Server page болон `GET /api/vehicles/:id` нь ижил service/presenter ашиглана. Нийтэлсэн + available машинаас бусад, байхгүй болон буруу ID-д 404; хадгалалтын алдаа error boundary-д очно. Жишээ fallback байхгүй; fixture зөвхөн test хавтаст байна. Түр noindex/nofollow хэвээр.
- Цагаан суурь, desktop дээр зураг/товч мэдээллийн хоёр багана; mobile нэг багана. Зураг бүтнээрээ багтана. Үнэ, төлөв, он/гүйлт/түлш, хоёр багана үзүүлэлт, тайлбар, тоноглол, компанийн бодит хаяг болон нийтлэг CarCardItem-тай санал болгох хэсэгтэй.
- Үндсэн зураг эхэнд, product_images нь sortOrder/id дарааллаар араас нь гарна; үндсэн зургийг давхардуулахгүй. URL нь `/files/:id/:originalName`. Үндсэн зургийн хүрээ 4:3, object-cover тул хүрээг дүүргэж, зах хэсэг тайрагдаж болно. Томруулсан зураг object-contain хэвээр. Хоосон зураг ч ижил харьцаатай. `lg` (1024px)-ээс олон зургийн thumbnail баруун талд босоогоор, үндсэн зурагтай ижил өндөрт багтана; илүү зургууд зөвхөн жижиг жагсаалт дотроо scroll хийнэ. Mobile/tablet дээр доод хэвтээ мөр болно. Сонгосон зураг болон breakpoint өөрчлөгдөхөд идэвхтэй thumbnail харагдах хэсэгт шилжинэ. Нэг зурагтай үед thumbnail/суман control болон хажуугийн зай нуугдана. Томруулсан native dialog нь Escape/хаах товчтой, focus буцаадаг, арын scroll түгжихдээ scrollbar-ийн зайг нөхнө. Зураггүй/зураг ачаалсангүй төлөвтэй.
- Утгагүй үзүүлэлт, тайлбар, тоноглол болон видеог нууна. Гүйлтийн 0 утгыг хадгална; EV дээр cc харуулахгүй. Үнэ асуух төлөвийн дотоод үнийг харуулахгүй. Видео нь зөвхөн баталгаажсан YouTube URL-д гарна.
- Зургийн дээрх буцах холбоос/toolbar мөр байхгүй. Машины мэдээллийн хэсэгт үнийн доор зөвхөн Харьцуулах, Хуваалцах гэсэн ижил хэмжээтэй хоёр товч байрлана. Хадгалах/хэвлэх товч байхгүй. Харьцуулах нь зөвхөн тухайн UI-ийн түр сонголт; refresh хийхэд арилна, харьцуулалтын жагсаалт болон account/API холболтгүй. Хуваалцах нь browser-ийн share боломж, байхгүй үед clipboard ашиглана; алдаанд гараар хуулах холбоос харуулна.
- Admin-ийн дэлгэрэнгүй HTML агуулгыг server дээр зөвшөөрсөн tag/link-ээр цэвэрлэнэ; script/iframe/event/style ажиллуулахгүй. Тоноглол, салбар, байршлын нэрс бодит лавлахаас ирнэ. Санал болгох нь өөрийг нь хассан, давхардалгүй 4 хүртэл машин: ижил төрөл, дараа нь ижил марк, хүрэлцэхгүй бол нийт public каталог. Үр дүнгүй бол хэсэг нуугдана.
- CRM form, лавлагаа илгээх, баталгаагүй дилерийн утас/имэйл нэмээгүй. Харьцуулалтын дэлгэц болон мэдээлэл илгээх холболт тусдаа ажил.

## Not Found

- `src/app/not-found.tsx` нь нийтлэг 404 дэлгэц. Үл мэдэгдэх URL, байхгүй Page, байхгүй/нийтэд харагдахгүй автомашин бүгд ижил UI ашиглана; машины тусгай 404 текст болон зарагдсан гэсэн таамаг харуулахгүй.
- Header/footer болон сайтын хүрээ хэвээр. Цагаан суурьтай, хүрээгүй голлосон агуулга: цайвар том 404, «Хуудас олдсонгүй», ерөнхий тайлбар, primary «Автомашин үзэх» `/vehicles`, энгийн «Нүүр хуудас» `/` холбоос. Mobile босоо, `sm`-ээс холбоосууд зэрэгцэнэ.
- Responsive тогтмол font хэмжээ, keyboard focus, 48px-ээс багагүй холбоосын өндөртэй. Redirect, animation, нэмэлт API болон шинэ theme байхгүй.

## Footer

- `src/components/footer/index.tsx`: бүх public хуудсанд root layout-аас ашиглах static footer. DB/API, CMS тохиргоо шаардахгүй.
