# UI / UX баримт бичиг

BigMotors LLC веб сайтын харагдах байдал, хэрэглэгчийн туршлагатай холбоотой баримтыг энд хадгална.

## Агуулга

- Сайтын бүтэц, хуудас хоорондын навигаци
- Каталог үзэх, шүүх, автомашины дэлгэрэнгүй мэдээлэл үзэх, холбоо барих хэрэглэгчийн урсгал
- Хуудасны бүдүүвч, дэлгэцийн загвар, Figma холбоос
- Өнгө, үсгийн хэв, зай хэмжээ, дүрс болон нийтлэг компонентын дүрэм
- Гар утас, таблет, компьютерын дэлгэцэд зохицох загвар
- Ачаалж буй, хоосон, алдаатай болон үр дүн олдоогүй төлөв
- Хүртээмж: уншигдах байдал, өнгөний ялгарал, гарын товчлуураар ашиглах боломж

## Хөтлөх зарчим

Загвар бүрд холбогдох хуудас, хэрэглэгчийн зорилго, хувилбар, батлагдсан эсэх болон шийдээгүй асуудлыг тэмдэглэнэ. Боломжийн шаардлагыг [features](../features/README.md)-тай холбоно.
