# Admin UI kit ашиглах дүрэм

- Төлөв: Баталсан
- Огноо: 2026-09-12
- Хамрах хүрээ: `sysop/app`. Public website-ийн UI kit-ийг энэ баримтаар тогтоохгүй.
- Холбоотой шийдвэр: [ADR 0027](../adr/0027-use-app-local-admin-ui-kit.md)
- Жишиг: [UI demo](../features/admin-ui-demo.md), `/demo/list`, `/demo/form`

## Үндсэн сан

- UI компонентод Mantine ашиглана. Ижил зориулалтын өөр UI сан давхар нэмэхгүй.
- Icon нь зөвхөн `@tabler/icons-react`. Байгаа icon-ийг гараар дахин зурахгүй.
- Mantine-ийн бэлэн компонент, prop болон theme боломжийг эхэлж ашиглана. Зөвхөн хүрэлцэхгүй layout/style-ийг төслийн CSS-ээр нөхнө.

## Custom CSS

- Баталсан: 2026-09-12. Custom CSS аль болох бичихгүй; Mantine-ийн бэлэн боломжийг үндсэн сонголт болгоно.
- Layout-д `Stack`, `Group`, `Grid`, `SimpleGrid`, `Flex`, `Box` зэрэг Mantine компонент, зай/хэмжээ/өнгөд style props болон theme/token ашиглана. Responsive байрлалыг боломжтой үед тухайн компонентын responsive props-оор шийднэ.
- Нийтлэг харагдацыг theme болон component-ийн тохиргоонд нэгтгэнэ. Mantine-ийн бэлэн боломжийг давтсан CSS class, selector болон media query нэмэхгүй.
- Props/theme-ээр шийдэх боломжгүй шаардлагад л хамгийн бага хүрээтэй custom CSS эсвэл Styles API ашиглана. Яагаад шаардлагатайг кодын ойролцоо товч тайлбарлана.
- CSS файлыг багасгах нэрээр их хэмжээний inline `style` / `styles` объект руу шилжүүлэхгүй; энэ нь мөн custom styling-д тооцогдоно.
- Өмнөх custom CSS-ийг бөөнөөр нь дахин бичихгүй. Тухайн хэсэгт засвар хийх үед бэлэн боломжийг шалгаж, өөрчлөлтийн хүрээнд хялбарчилна.

## Хуудас ба body

- Нийтлэг sidebar/header нь `AdminLayout`-д, тухайн дэлгэц нь router-ийн `Outlet` дотор байна.
- Хуудасны гарчиг болон navigation/tab нь үндсэн ажлын box-ийн гадна байрлана.
- Form болон жагсаалт зэрэг үндсэн ажлын хэсгийг цагаан дэвсгэртэй, нимгэн хүрээтэй, 6px булантай, сүүдэргүй нэг box дотор байрлуулна.
- Box дотор дахин box үүсгэхгүй. Доторх хэсгүүдийг гарчиг, зай болон divider-аар ялгана.
- Жишиг padding: desktop 24px, mobile 16px. Form box хамгийн ихдээ 850px; жагсаалтын body боломжит өргөнөө ашиглана.
- UI төлөв болон урт утга өөрчлөгдөхөд toolbar, icon button, table-ийн бүтэц үсрэхгүй. Mobile дээр текст, control давхцахгүй, хуудас хөндлөн overflow үүсгэхгүй.

## Theme ба хэмжээ

- Өнгө, typography, spacing болон хэмжээний үндсэн эх сурвалж нь Mantine theme/token байна. Дэлгэц бүрд тусдаа палитр, ижил утгатай шинэ хэмжээ зохиохгүй.
- Төслийн онцлог утгыг нийтлэг theme/token эсвэл shared style-д нэг удаа тодорхойлно. Дээрх box-ийн 6px, 24px, 16px, 850px утгууд мөн нийтлэг дүрэмд хамаарна.
- Text нь theme-ийн font-ийг дагана; viewport-ийн өргөнөөр font хэмжээг өсгөж/бууруулахгүй. Letter spacing 0 байна.
- Эцсийн брэндийн palette/font-ийг энэ баталгаажуулалтаар сонгоогүй. Шинэчилбэл нийтлэг theme түвшинд өөрчилнө.

## Form

- 2026-09-12: Form-ийн төлөвийг `@mantine/form`-ийн `useForm`-оор удирдана. [ADR 0028](../adr/0028-use-mantine-form-without-query-cache.md). Demo-г шилжүүлэх кодын ажил хараахан хийгдээгүй.

- Энгийн form нэг багана; холбоотой талбарууд desktop дээр хоёр багана байж болно. Mobile дээр нэг багана болно.
- Input бүр харагдах label-тай байна; placeholder нь label-ийг орлохгүй. Required талбарыг тэмдэглэж, алдааг тухайн талбартай холбоно.
- Сонголтод select/menu, хоёр төлөвт switch/checkbox, тоон утгад зориулалтын numeric input/stepper ашиглана.
- Хадгалах, Болих болон Анхны утга зэрэг үйлдлүүд тогтсон дараалалтай байна. Хадгалах нь primary, туслах үйлдлүүд secondary/subtle байна.
- Demo-ийн талбар, native validation болон жишээ утгууд нь бодит бүтээгдэхүүний schema, бизнес дүрэм эсвэл production form сангийн шийдвэр биш.

## Жагсаалт

- Дараалал: toolbar → table → pagination. Нэмэх болон бусад нийтлэг үйлдэл toolbar орчимд байрлана.
- Хайлт, шүүлт, эрэмбэ болон page нь URL query-д байна. Шүүлт өөрчлөхөд pagination эхлэл рүү буцна.
- Мөрийн засах/устгах зэрэг үйлдэл icon button байна; tooltip болон accessible name-тай байна.
- Mobile дээр өргөн хүснэгт зөвхөн өөрийн scroll хэсэгт гүйнэ; бүтэн хуудас хажуу тийш сунгахгүй.
- Хоосон сан болон шүүлтээр үр дүн олдоогүй төлөвийг тохирох мессеж, боломжтой дараагийн үйлдлээр харуулна.

## Үйлдэл ба төлөв

- Primary үйлдлийг тод өнгөөр ялгана. Устгах үйлдэл улаан бөгөөд confirmation dialog-той байна.
- Хэрэгжээгүй үйлдлийг ажилладаг мэт харуулахгүй; disabled төлөв эсвэл харагдахгүй байдлаар шийднэ.
- Loading, empty, error, success болон disabled төлөвийг тухайн урсгалд шаардлагатай бол заавал хэрэгжүүлнэ.
- Хадгалж байх үед давхар submit-ээс сэргийлнэ. Алдаа гарвал бөглөсөн утгыг алдахгүй; success нь бодитоор амжилттай болсон үйлдлийг илэрхийлнэ.
- Алдааны UI-д stack, token болон дотоод нууц мэдээлэл харуулахгүй.

## Хүртээмж

- Input label, icon button-ийн tooltip/accessible name болон keyboard navigation-ийг хангана.
- Focus харагдах ёстой. Modal хаах болон focus буцаах зэрэг боломжид Mantine-ийн бэлэн зан төлөвийг ашиглана.
- Төлөвийг зөвхөн өнгөөр илэрхийлэхгүй; текст эсвэл танигдах icon дагалдана.

## Дундын компонент

- Admin дотроо давтагддаг нийлмэл хэсгийг `sysop/app/src/ui/` дотор нэгтгэнэ. Одоохондоо тусдаа `packages/uikit` үүсгэхгүй.
- Mantine-ийн компонент бүрийг wrapper болгохгүй. Давталт эсвэл нэг мөр дүрэм баримтлуулах бодит хэрэгцээтэй үед `PageBody`, `FormActions`, `EmptyState` зэрэг компонент үүсгэж болно.
- Shared UI компонент нь домэйн API/DB логик эзэмшихгүй. Өгөгдөл, callback болон төлөвийг caller-оос авна.
- Энэ баталгаа нь дээрх компонентуудыг аль хэдийн үүсгэсэн гэсэн үг биш. Одоогийн demo нь жишиг; шаардлагатай үед нийтлэг хэсгийг салгана.

## Шалгах жагсаалт

- Mantine/Tabler болон нийтлэг theme дүрмийг дагасан эсэх.
- Custom CSS нэмэхээс өмнө Mantine-ийн component, props, theme боломжийг ашигласан эсэх; үлдсэн custom style бодит шаардлагатай, хамгийн бага хүрээтэй эсэх.
- Нэг body box, form/list байрлал, үйлдэл болон төлөвүүд нийцсэн эсэх.
- Desktop/mobile дээр текст, input, button багтаж, keyboard-аар ашиглагдаж байгаа эсэх.
- Shared компонент давхардаагүй, шаардлагагүй wrapper болон шинэ UI сан нэмээгүй эсэх.

## Өгөгдөл ба cache

2026-09-12: [ADR 0028](../adr/0028-use-mantine-form-without-query-cache.md)-аар TanStack Query болон нэмэлт cache хэрэглэхгүй байхаар баталсан. API-гаас шаардлагатай үед уншиж, mutation амжилттай бол хамаарах өгөгдлийг дахин уншина. Query cache сан, өөрсдийн cache wrapper болон persistence нэмэхгүй.

## Нээлттэй шийдвэр

Form mode, Zod schema resolver болон payload mapping-ийн нарийвчилсан integration, global state хэрэгцээ болон website styling тусдаа үлдэнэ. Website-ийн cache сонголтыг admin-ийн cache-гүй шийдвэрээр өөрчлөхгүй.
