# Admin UI demo

- Баталсан: 2026-09-12
- Хүрээ: `sysop/app` доторх тусгаарласан UI жишээ. Бодит каталогийн CRUD биш.

## Хуудас

| URL | Агуулга |
| --- | --- |
| `/demo` | Жишээ бүртгэлийн тоо, жагсаалт/form руу шилжих холбоос |
| `/demo/list` | Table, хайлт, төрөл/төлөвийн шүүлт, үнэ/нэрийн эрэмбэ, pagination, нэмэх/засах/устгах |
| `/demo/form` | Нэмэх жишээ form |
| `/demo/form?id=demo-001` | Сонгосон жишээ бүртгэл засах |

## Зааг

- `Жишээ өгөгдөл` тэмдэглэгээтэй; нэр, үнэ, төлөв нь компанийн бодит мэдээлэл биш.
- Бүртгэлүүд зөвхөн demo layout-ийн React state-д байна. Demo дотор шилжихэд хадгалагдана; refresh хийх эсвэл demo-оос гараад буцаж ороход анхны 12 мөр сэргээнэ. Шинээр үүсгэсэн ID нь refresh-ийн дараа олдохгүй.
- API, DB, localStorage, upload болон auth/ACL-д хүрэхгүй. Бодит products schema эсвэл бизнес дүрмийг энэ form-оор батлахгүй.
- Form нь Mantine input, React state болон HTML validation ашиглана. Нэр required/255, богино тайлбар optional/512, үнэ 0–999999999999 бүхэл тоо. Энэ нь UI жишээний хязгаар; бодит нийтлэх дүрэм биш.
- 2026-09-12: [ADR 0028](../adr/0028-use-mantine-form-without-query-cache.md)-аар `useForm` ашиглаж, нэмэлт cache үүсгэхгүй байхаар баталсан. Одоогийн demo-ийн React state/HTML validation хэрэгжүүлэлтийг `useForm` руу шилжүүлэх ажил хараахан хийгдээгүй; demo-ийн API/DB-гүй хүрээ хэвээр.
- Хайлт/шүүлт/эрэмбэ/page URL query-д байна. Шүүлт солиход page эхлэл рүү буцна; байхгүй эсвэл хэтэрсэн page-ийг боломжтой хүрээнд харуулна.
- Устгах нь confirmation dialog-той. Хоосон жагсаалт, үл мэдэгдэх edit ID болон хадгалсан/устгасан мэдэгдэлтэй.

## Хүлээн авах шалгуур

- 2026-09-12: Demo-ийн body нь цагаан дэвсгэр, 1px хүрээ, 6px булантай нэг box байна. Гарчиг/tab гадна байрлана; дотор нь давхар box нэмэхгүй. Desktop padding 24px, mobile 16px; form box хамгийн ихдээ 850px өргөнтэй.

- Гурван URL шууд нээгдэж, sidebar болон demo navigation-аар шилжинэ.
- Хайлт, нийлмэл шүүлт, эрэмбэ, pagination болон хоосон төлөв ажиллана.
- Required/тоон хязгаар шалгагдаж, нэмэх/засах/болих/анхны утга/устгах үйлдлүүд зөвхөн жишээ өгөгдөлд үйлчилнэ.
- Mobile дээр form нэг багана, table өөрийн scroll хэсэгтэй; нийт хуудас хөндлөн overflow-гүй байна.
