# Дугуйн бүртгэлийн талбарууд

- Огноо: 2026-09-10
- Төлөв: Хэсэгчлэн баталсан; лавлах, enum/const ангилал болон нийтлэг бүтээгдэхүүний дүрэм батлагдсан; онцлог талбарын үлдсэн санал нээлттэй
- Холбоотой баримт: [Бүтээгдэхүүний хүрээ](scope.md), [DB хэлэлцүүлэг](../db/README.md), [Нийтлэг item талбарын дүрэм](vehicle-fields.md#product-ийн-жагсаалтын-талбарууд)

## Зорилго ба зааг

**2026-09-10-ны шинэчилсэн баталгаа:** [Tires болон markings schema](../db/catalog-schema-proposal.md#tires) батлагдсан. Нийтлэхэд brand, model, condition, size_label, season, price_unit, availability болон эхний метр хэмжээний хүрээнд width/aspect/rim/construction заавал. Төрөл дотроо unique SKU, нэг салбар, ижил хэмжээтэй хос/иж бүрдэл, үлдэгдлийн тоогүй каталог болон enum утгууд батлагдсан. Used-ийн ширхэг/багцын нарийвчлал батлагдтал used нийтлэхгүй; метр бус хэмжээ, mixed-size багц, олон салбар, элэгдэл/DOT/үйлдвэрлэлийн огноо тусдаа хэвээр. Энэ шийдвэр тухайн хүрээнд доорх анхны саналыг орлоно.

Дугуйг каталогт бүртгэх, танилцуулах болон admin-аас мэдээллийг удирдахад хэрэгтэй талбаруудын санал. Нэг бүртгэл ижил бүтээгдэхүүний төрөл/хэмжээг төлөөлж, олон ширхэгтэй байж болох батлагдсан зарчим хэвээр. Дугуйг сэлбэгийн дэд ангилалд нэгтгэхгүй.

Доорх 33 талбарын саналаас [3 үндсэн лавлах, 11 enum/const бүлэг болон тоон утга/код/boolean-ийн зааг](../db/tire-reference-data.md) батлагдсан. 2026-09-10-ны дараагийн баталгаагаар [автомашинтай ижил нийтлэг дүрэм](product-common-rules.md) дугуйд үйлчилнэ: текст, rich text, зураг, үнэ, нийтлэлийн төлөв/default, дотоод тэмдэглэл, идэвхгүй лавлах болон каталогийн нийтлэг үйлдэл. Тусгай хэмжээ/индекс, нэмэлт requiredness/public/filter matrix нээлттэй; бүх талбар, DB schema эсвэл API contract баталсан гэсэн үг биш.

Иж бүрдлийн тоо нь агуулахын үлдэгдэл биш. Нэг бүртгэл олон ширхэгийг төлөөлөх тул нэг дугуйг борлуулснаар бүх бүртгэлийг зарагдсан гэж үзэхгүй. Бэлэн байдал болон нийтлэлийн төлөв тусдаа байна; нийтлэлийн төлөв автоматаар өөрчлөгдөхгүй.

`stock_quantity`, агуулахын хөдөлгөөн, нийлүүлэлт, захиалга, төлбөрийн мэдээлэл нэмээгүй. Ижил хэмжээтэй иж бүрдэл болон урд/хойд өөр хэмжээтэй багцын бүртгэлийн аргыг тусад нь шийднэ; нэг хэмжээний талбараар ялгаатай дугуйг ижил гэж үзэхгүй.

## Нийтлэг item талбарууд

Дугуйд `description` (512) нь short description, SEO, share-д ашиглагдана; ноорог болон нийтлэхэд сонголттой. `item_title` (255), `item_desc` (512), `item_image_id` бүгд сонголттой. Render дээр харгалзах `title`, `description`, `main_image_id`-аас автоматаар авна; `content`-оос item тайлбар үүсгэхгүй. [Нийтлэг дүрэм](product-common-rules.md)-ийн зураг/үнэ, лавлахын хамаарал болон идэвхгүй лавлахтай засах/нийтлэх дүрэм бүгд үйлчилнэ. Дугуйн хэмжээ, индекс зэрэг тусгай шаардлагыг автомашины талбараар орлуулахгүй.

## Ширхэг ба нийлүүлэлтээс хамаарах мэдээлэл

Үйлдвэрлэлийн огнооны дөрвөн оронтой тэмдэглэгээ нь долоо хоног, оныг илэрхийлдэг. [Michelin үйлдвэрлэлийн огнооны тайлбар](https://www.michelinman.com/auto/auto-tips-and-advice/tires-101/tire-markings-explained).

Манай загварт нэг бүтээгдэхүүн олон ширхэгийг төлөөлөх тул үйлдвэрлэсэн долоо хоног/он, DOT/TIN дугаар, хуучин дугуйн үлдсэн хээний гүн, гэмтэл болон засварын мэдээллийг бүх ширхэгт ижил гэж хадгалахгүй байх саналтай. Эдгээрийг нийтлэг бүтээгдэхүүний 33 талбарт одоогоор оруулаагүй; нийлүүлэлтийн багц эсвэл бодит ширхэг/иж бүрдлийн түвшинд бүртгэх эсэхийг дараа шийднэ. Энэ тэмдэглэл нь агуулахын модуль баталсан гэсэн үг биш.

## Дараагийн шийдвэрүүд

- Талбарын жагсаалтын үлдсэн саналыг батлах, хэрэггүй талбарыг хасах; лавлахын батлагдсан шийдвэрийг хадгална.
- Нийтлэг дүрмээс гаднах тусгай талбарын нийтлэх шаардлага, public харагдах байдал болон хайлт/шүүлтийн талбарууд.
- Ижил бүтээгдэхүүнийг брэнд, загвар, хэмжээ, индекс болон тусгай хувилбараар ялгах дүрэм.
- Метр бус хэмжээ, хүнд даацын болон бусад тусгай зориулалтын дугуй багтах эсэх.
- Үйлдвэрлэсэн огноо, хуучин дугуйн элэгдэл/гэмтэл, иж бүрдэл болон олон салбарын бүртгэлийн зааг.
- Үлдэгдлийн тоо хөтлөх эсэх; үнийн нэгж, бэлэн байдал болон дугуйн тусгай сонголтын бүрэн жагсаалт. Үнэ/валют, үнэ харуулах хэлбэр болон нийтлэлийн төлөв нийтлэг дүрмээр батлагдсан.

## Хүлээн авах шалгуурын санал

1. Өргөн, харьцаа, обудны диаметр болон хийц хоорондоо ялгаатай байна; бүрэн тэмдэглэгээтэй зөрөхгүй.
2. Ижил брэнд/загвар боловч өөр хэмжээ, индекс эсвэл тусгай хувилбартай дугуйг нэг бүтээгдэхүүн гэж автоматаар нэгтгэхгүй.
3. Үнийн нэгж ба иж бүрдлийн агуулгыг үлдэгдлийн тооноос ялгана.
4. Үйлдвэрлэсэн огноо эсвэл хуучин дугуйн элэгдлийг олон ширхэгт таамгаар ижил оноохгүй.
5. Нийтлэг `item_*` дүрмийг хадгална; CRM, агуулах, онлайн худалдаа болон DB schema хэрэгжүүлэлт нэмэхгүй.
