# Дугуйн бүртгэлийн талбарууд

- Огноо: 2026-09-10
- Төлөв: Санал болгосон; талбарын жагсаалтыг баталгаажуулах
- Холбоотой баримт: [Бүтээгдэхүүний хүрээ](scope.md), [DB хэлэлцүүлэг](../db/README.md), [Нийтлэг item талбарын дүрэм](vehicle-fields.md#product-ийн-жагсаалтын-талбарууд)

## Зорилго ба зааг

Дугуйг каталогт бүртгэх, танилцуулах болон admin-аас мэдээллийг удирдахад хэрэгтэй талбаруудын санал. Нэг бүртгэл ижил бүтээгдэхүүний төрөл/хэмжээг төлөөлж, олон ширхэгтэй байж болох батлагдсан зарчим хэвээр. Дугуйг сэлбэгийн дэд ангилалд нэгтгэхгүй.

Доорх 33 талбар нь санал; заавал бөглөх, public харуулах, шүүлтэд ашиглах дүрмийг дараа батална. DB schema, API contract, агуулах, CRM болон онлайн худалдаа хэрэгжүүлэхгүй. Өмнө батлагдсан нийтлэг `item_*` дүрмийг хадгална.

| T06 | Нөхцөл | Шинэ/хуучин зэрэг сонголтыг дараа батална; хуучин дугуйн нэг бүртгэлийн заагийг тусад нь нарийвчилна |

| T07 | Өргөн | Метр хэмжээтэй дугуйн хувьд мм; жишээ: 225 |
| T08 | Хажуу ханын өндөр/өргөний харьцаа | Хувиар; жишээ: 65. Энэ нь өндөр мм-ээр гэсэн үг биш |
| T09 | Обудны диаметр | Инчээр; жишээ: 17 |

| T11 | Хэмжээний бүрэн тэмдэглэгээ | Үйлдвэрлэгчийн бичлэг, жишээ: 225/65 R17; угтвар болон тусгай хэмжээний тэмдэглэгээг алдахгүй |

Метр хэмжээний өргөн, харьцаа, хийц, обудны диаметрийн утгыг үйлдвэрлэгчийн тайлбартай тулгасан. [Michelin хэмжээний тэмдэглэгээ](https://www.michelinman.com/auto/auto-tips-and-advice/tires-101/tire-markings-explained).

Метр бус болон тусгай хэмжээтэй дугуйг дэмжих эсэхийг дараа тогтооно; тэдгээрийн өргөнийг хүчээр мм, харьцааг зохиомол утга болгож оруулахгүй. Бүрэн тэмдэглэгээг гараар оруулах эсвэл тусдаа утгуудаас үүсгэх арга, зөрүүг шалгах дүрэм нээлттэй.

| T15 | Ачааллын индекс | Үйлдвэрлэгчийн индекс; шууд кг утга биш. Хос индекс байвал мэдээллийг алдахгүй |
| T16 | Хурдны индекс | Үйлдвэрлэгчийн тэмдэглэгээ; зөвлөмжит жолоодох хурд биш |

| T19 | Хадаасны төрөл / төлөв | Хадаастай, хадаас суулгах боломжтой, хадаасгүй гэсэн санал; зөвхөн өвлийн гэдгээс таамаглахгүй |

Ачаалал/хурд болон нэмэлт тэмдэглэгээний утгыг үйлдвэрлэгчийн эх сурвалжаар шалгана. [Continental дугуйн тэмдэглэгээ](https://www.continental-tires.com/tire-knowledge/tire-markings/), [Michelin тайлбар](https://www.michelinman.com/auto/auto-tips-and-advice/tires-101/tire-markings-explained).

Улирал, замын зориулалт, даац болон үйлдвэрлэгчийн тэмдэглэгээг нэг ангилалд холихгүй байх саналтай. Тодорхойгүй мэдээллийг үйлдвэрлэгчийн баримтгүйгээр нөхөхгүй. Автомашинд тохирох эсэхийг зөвхөн хэмжээгээр нь баталгаажуулах функц энэ саналд ороогүй.

| ID | Талбар | Утга, тайлбар |

| T21 | Үнэ | Заасан нэгжийн үнэ |
| T22 | Валют | Үнийн валют |

| T24 | Үнийн нэгж | Үнэ нэг ширхэг, хос эсвэл иж бүрдлийн алинд хамаарахыг тодорхойлно |
| T25 | Иж бүрдлийн агуулга | Хэдэн дугуй багтах, ижил эсвэл өөр хэмжээтэй эсэх; зөвхөн иж бүрдэлд хамаарна |
| T26 | Бэлэн байдлын төлөв | Бэлэн, түр дууссан, ирэх зэрэг санал; сонголт болон шилжилтийг дараа батална |
| T27 | Байршил / салбар | Бүтээгдэхүүн байгаа салбар; олон салбарын мэдээллийг тусад нь шийднэ |

Иж бүрдлийн тоо нь агуулахын үлдэгдэл биш. Нэг бүртгэл олон ширхэгийг төлөөлөх тул нэг дугуйг борлуулснаар бүх бүртгэлийг зарагдсан гэж үзэхгүй. Бэлэн байдал болон нийтлэлийн төлөв тусдаа байна гэсэн саналтай.

`stock_quantity`, агуулахын хөдөлгөөн, нийлүүлэлт, захиалга, төлбөрийн мэдээлэл нэмээгүй. Ижил хэмжээтэй иж бүрдэл болон урд/хойд өөр хэмжээтэй багцын бүртгэлийн аргыг тусад нь шийднэ; нэг хэмжээний талбараар ялгаатай дугуйг ижил гэж үзэхгүй.

## Нийтлэг item талбарууд

Дугуйд мөн `item_title`, `item_desc`, `item_image` хэрэглэнэ. Нийтлэхэд гарчиг, зураг заавал, тайлбар сонголттой бөгөөд хоосон утгыг дэлгэрэнгүй мэдээллээс автоматаар орлуулахгүй гэсэн [батлагдсан дүрэм](vehicle-fields.md#product-ийн-жагсаалтын-талбарууд) хэвээр. Автомашины бусад бөглөх шаардлага болон default-ыг дугуйд автоматаар шилжүүлэхгүй.

## Ширхэг ба нийлүүлэлтээс хамаарах мэдээлэл

Үйлдвэрлэлийн огнооны дөрвөн оронтой тэмдэглэгээ нь долоо хоног, оныг илэрхийлдэг. [Michelin үйлдвэрлэлийн огнооны тайлбар](https://www.michelinman.com/auto/auto-tips-and-advice/tires-101/tire-markings-explained).

Манай загварт нэг бүтээгдэхүүн олон ширхэгийг төлөөлөх тул үйлдвэрлэсэн долоо хоног/он, DOT/TIN дугаар, хуучин дугуйн үлдсэн хээний гүн, гэмтэл болон засварын мэдээллийг бүх ширхэгт ижил гэж хадгалахгүй байх саналтай. Эдгээрийг нийтлэг бүтээгдэхүүний 33 талбарт одоогоор оруулаагүй; нийлүүлэлтийн багц эсвэл бодит ширхэг/иж бүрдлийн түвшинд бүртгэх эсэхийг дараа шийднэ. Энэ тэмдэглэл нь агуулахын модуль баталсан гэсэн үг биш.

## Дараагийн шийдвэрүүд

- Талбарын жагсаалтыг батлах, хэрэггүй талбарыг хасах.
- Ноорог/нийтлэх үед заавал бөглөх эсэх, public харагдах байдал, шүүлт ба эрэмбэ.
- Ижил бүтээгдэхүүнийг брэнд, загвар, хэмжээ, индекс болон тусгай хувилбараар ялгах дүрэм.
- Метр бус хэмжээ, хүнд даацын болон бусад тусгай зориулалтын дугуй багтах эсэх.
- Үйлдвэрлэсэн огноо, хуучин дугуйн элэгдэл/гэмтэл, иж бүрдэл болон олон салбарын бүртгэлийн зааг.
- Үлдэгдлийн тоо хөтлөх эсэх; үнэ, нэгж, төлөв болон сонголтын бүрэн жагсаалт.

## Хүлээн авах шалгуурын санал

1. Өргөн, харьцаа, обудны диаметр болон хийц хоорондоо ялгаатай байна; бүрэн тэмдэглэгээтэй зөрөхгүй.
2. Ижил брэнд/загвар боловч өөр хэмжээ, индекс эсвэл тусгай хувилбартай дугуйг нэг бүтээгдэхүүн гэж автоматаар нэгтгэхгүй.
3. Үнийн нэгж ба иж бүрдлийн агуулгыг үлдэгдлийн тооноос ялгана.
4. Үйлдвэрлэсэн огноо эсвэл хуучин дугуйн элэгдлийг олон ширхэгт таамгаар ижил оноохгүй.
5. Нийтлэг `item_*` дүрмийг хадгална; CRM, агуулах, онлайн худалдаа болон DB schema хэрэгжүүлэлт нэмэхгүй.
