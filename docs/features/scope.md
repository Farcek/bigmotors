- Үндэслэл: Хэрэглэгчийн шаардлага: автомашин, сэлбэг хэрэгсэл, дугуйн каталог байна, сайтаар худалдахгүй; CRM-ийг тусдаа системээр боловсруулна
- Холбоотой баримт: [Features бүртгэл](README.md), [Төслийн танилцуулга](../../README.md)

## Зорилго

BigMotors LLC-ийн автомашин, сэлбэг хэрэгсэл, дугуй болон компанийн мэдээллийг танилцуулах public website байна. Энэ нь бүтээгдэхүүний каталог болохоос онлайн худалдааны систем биш. Аль ч төрлийн бүтээгдэхүүн худалдан авах тохиролцоо болон төлбөрийг энэ сайтаар гүйцэтгэхгүй.

## Үндсэн бүтээгдэхүүний төрлүүд

1. **Автомашин**
2. **Сэлбэг хэрэгсэл**
3. **Дугуй**

Эдгээр нь каталогийн үндсэн гурван төрөл байна. Дугуйг сэлбэг хэрэгслийн дэд ангилалд нэгтгэхгүй, үндсэн төрөл гэж тусад нь авч үзнэ. Төрөл бүрийн дэд ангилал, талбар, шүүлт болон дэлгэрэнгүй мэдээллийг дараа тогтооно. Энэ ангилал нь DB хүснэгтийн бүтцийг тогтоохгүй.

Бүртгэлийн нэгж батлагдсан: автомашины нэг бүртгэл нэг бодит машиныг, сэлбэг болон дугуйн нэг бүртгэл ижил бүтээгдэхүүний төрөл/хэмжээг төлөөлж, олон ширхэгтэй байж болно. Үлдэгдлийн тоо хөтлөх болон харуулах боломжийг хараахан батлаагүй. Дэлгэрэнгүйг [өгөгдлийн загварын хэлэлцүүлэг](../db/README.md)-д хөтөлнө.

## Батлагдсан хүрээ

Одоогийн ажил автомашин, сэлбэг хэрэгсэл, дугуйн каталог болон тэдгээрийн мэдээллийг удирдах admin хэсэгт төвлөрнө. Өмнө баталсан компанийн танилцуулга болон PWA шаардлагыг цуцлаагүй; тэдгээрийн нарийвчлалыг дараа хэлэлцэнэ.

| Хэсэг | Хүрээ | Нарийвчлах зүйл |
| --- | --- | --- |
| Автомашины каталог | BigMotors-ийн автомашинуудыг танилцуулах | Жагсаалт, дэлгэрэнгүй, харуулах талбар, шүүлт ба эрэмбэ |
| Сэлбэг хэрэгслийн каталог | BigMotors-ийн сэлбэг хэрэгслийг танилцуулах | Дэд ангилал, жагсаалт, дэлгэрэнгүй, талбар, шүүлт ба эрэмбэ |
| Дугуйн каталог | BigMotors-ийн дугуйг танилцуулах | Жагсаалт, дэлгэрэнгүй, талбар, шүүлт ба эрэмбэ |
| Компанийн танилцуулга | BigMotors LLC-ийн тухай мэдээлэл | Агуулга, хуудасны бүтэц, холбоо барих сувгууд |
| Gallery module | Gallery, зурагтай item-ийн schema/DTI/API/admin CRUD | [Удирдлага](admin-gallery.md); website байршуулалт тусдаа |
| Admin | Каталогийн мэдээлэл удирдах frontend/backend төсөлд багтана; CRM биш | Бүтээгдэхүүний мэдээлэл, үйлдэл, эрх болон нийтлэх урсгал |
| PWA | Public website PWA дэмжинэ | [PWA-ийн нарийвчилсан хүрээ](pwa.md) |

[Нэгж автомашины талбарууд ба бөглөх шаардлага](vehicle-fields.md), төлөвийн сонголт, төлөв шилжилт болон зарагдсан машины харагдах байдал батлагдсан. [Автомашины public талбар, хайлт, шүүлт, эрэмбэ](vehicle-catalog.md) мөн батлагдсан; хайлтын нарийвчилсан тохирол, хуудаслалт, сэлбэг/дугуйн тусгай талбар, admin-ийн CRUD үйлдэл бүр болон эцсийн UI загвар нээлттэй хэвээр.

## Хүрээнээс гадуур

**CRM нь тусдаа систем байна; `bm-website` дотор хөгжүүлэхгүй.** Харилцагч/lead бүртгэл, хүсэлтийн төлөв, ажилтанд оноох, дотоод тэмдэглэл, follow-up болон борлуулалтын pipeline нь энэ төслийн ажил биш. Каталогийн admin хэрэглэгчийн нэвтрэлт, эрхийн удирдлага нь CRM-ийн харилцагчийн бүртгэлээс тусдаа ойлголт бөгөөд хэвээр үлдэнэ.

2026-09-10: [Admin login, user management, ACL](admin-authentication-access.md)-д Chip CRM-ийн Userly аргачлалыг ижил ашиглахаар баталсан. Account, invitation, password/reset, role/permission болон access lifecycle-г Userly удирдана; BigMotors дотор давхар local user-management screen хийхгүй. Catalog admin нь local identity profile, серверийн ACL/scope шалгалт, safe ACL runtime metadata/reload боломжтой байна. Энэ нь CRM-ийн бизнес module, HR, retention/purge эсвэл бүх Settings боломжийг хуулсан гэсэн үг биш.

Тусдаа CRM-тэй API холболт, хүсэлт дамжуулалт эсвэл өгөгдөл синхрончлох ажил одоогийн хүрээнд ороогүй. Лавлах form хэрэгтэй эсэх, хэрэгтэй бол мэдээллийг хаашаа дамжуулахыг тусад нь батална; CRM-ийг энэ төсөлд далд байдлаар нэмэхгүй.

Сайтаар худалдахгүй гэсэн заагийн дагуу дараах худалдааны урсгалыг хэрэгжүүлэхгүй:

- Худалдан авах сагс болон checkout.
- Сайт дотор автомашин, сэлбэг хэрэгсэл, дугуйн худалдааны захиалга үүсгэх, баталгаажуулах.
- Онлайн төлбөр, урьдчилгаа төлбөр, төлбөртэй захиалга эсвэл reservation.
- Онлайн худалдааны захиалга, төлбөр, буцаалтыг удирдах admin модуль.

Үнэ эсвэл борлуулалтын төлөв харуулах нь өөрөө онлайн худалдаа биш. Тэдгээрийг харуулах эсэх болон дүрмийг каталогийн шаардлагаар тусад нь тогтооно.

## Одоогоор Батлагдаагүй

- Лавлах хүсэлтийн form, буцааж залгах хүсэлт, туршилтын жолоодлогын цаг авах.
- Төлбөргүй reservation, зээлийн хүсэлт. Нүүр хуудасны жишиг тооцоолуур тусдаа батлагдсан.
- Public хэрэглэгчийн бүртгэл, хадгалсан автомашин, харьцуулалт.
- Гаднын хэрэглэгч автомашины зар нийтлэх боломж.
- Тусдаа CRM болон бусад системтэй холболт. CRM-ийг өөрийг нь энэ төсөлд хөгжүүлэхгүй.
- Олон хэл, үйлчилгээний тусдаа хуудас, онцлох автомашины хэсэг.

Эдгээр нь автоматаар багтсан ч биш, бүрмөсөн хориглосон ч биш. Нэмэх эсэхийг тус бүрээр хэлэлцэнэ. Лавлах хүсэлт зөвшөөрөгдсөн ч худалдааны захиалга эсвэл бүтээгдэхүүн баталгаатай захиалсан үйлдэл гэж үзэхгүй.

## Хүлээн Авах Суурь Шалгуур

- Public website нь каталог болон компанийн мэдээлэл танилцуулах зориулалттай байна.
- Каталог нь автомашин, сэлбэг хэрэгсэл, дугуй гэсэн үндсэн гурван төрлийг хамарна.
- Сайт дотор худалдан авалт дуусгах, худалдааны захиалга батлах, төлбөр авах урсгал байхгүй.
- Admin-д онлайн худалдааны захиалга/төлбөр удирдах модуль байхгүй.
- Энэ төсөлд CRM-ийн модуль, lead өгөгдлийн бүтэц, CRM API эсвэл CRM дэлгэц хэрэгжүүлэхгүй. CRM-ийн бэлэн байдал нь каталогийг хүлээн авах урьдчилсан нөхцөл биш.
- Батлагдаагүй боломжийг хэрэгжүүлэлтийн хүрээнд автоматаар нэмэхгүй.

## Дараагийн Хэлэлцүүлэг

Эхлээд автомашин, сэлбэг хэрэгсэл, дугуй тус бүрийн жагсаалт болон дэлгэрэнгүйд юу харуулахыг тогтооно. Дараа нь шүүлт/эрэмбэ, холбоо барих үйлдэл, admin-ийн мэдээлэл удирдах хүрээг нэг нэгээр нь батална. Эдгээрийг `docs/features/`-д хөтөлж, зөвхөн техникийн шийдвэрийн бүртгэл болох `docs.task.md`-тэй холихгүй.
