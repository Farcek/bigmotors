# Нүүр хуудасны зээлийн тооцоолуур

- 2026-09-13: Хэрэглэгчийн хүсэлтээр нүүр хуудасны автомашины жагсаалтын дараа нэмсэн.
- Component: `web/website/src/components/home.financing.calculator/index.tsx`.
- Зүүн талын дэвсгэр нь нүүрэнд анх ачаалсан автомашинуудаас зурагтай эхний бүртгэлийн үндсэн зураг. Зураггүй үед хар фон хэвээр байна. `imageUrl` prop-оор өөрчилж болно.
- Desktop: зурагтай дэвсгэр дээр баруун талд цагаан форм; mobile: нэг багана.
- Үнэ, жилийн хүү (%), хугацаа (сар), урьдчилгаа оруулж Тооцоолох дарна. Эхний утгууд нь жишээ, бодит банкны нөхцөл биш.
- Хэрэгжүүлэлтийн суурь: сарын тэнцүү төлбөртэй аннуитет. P = үнэ - урьдчилгаа, r = жилийн хүү / 1200, n = сар; сарын төлбөр = P × r / (1 - (1+r)^(-n)). 0% үед P/n.
- Нийт хүү = сарын төлбөр × сар - P. Нийт төлөх дүн = үнэ + нийт хүү, урьдчилгаа багтана. Тооцооллын дундуур тоймлохгүй, харуулахдаа бүхэл төгрөгөөр тоймлоно.
- Үнэ эерэг, жилийн хүү 0–100%, хугацаа 1–600 бүтэн сар, урьдчилгаа 0–үнэ. Эдгээр нь calculator-ийн оролтын хязгаар, банкны шалгуур биш.
- Буруу оролтод талбарын алдаа харуулж эхний алдаатай талбарт focus өгнө. Утга өөрчилбөл өмнөх үр дүн арилж, дахин тооцоолно.
- Шимтгэл, даатгал ороогүй. Банкны санал, зээлийн эрх тогтоох, хүсэлт авах, CRM, API/DB хадгалалт орохгүй.
- Баталгаажуулалт: үндсэн тооцоо, 0% хүү, бүрэн урьдчилгаа, буруу оролт, desktop/mobile форм.
