# Дугуйн лавлахын хоёр багана

- Төлөв: Хэрэгжүүлсэн, 2026-09-12.
- URL: `/references/tire-hierarchy`.
- Navigation: Лавлах → Дугуйн брэнд / Загвар.
- Жишиг: [Автомашины лавлах](admin-vehicle-hierarchy.md), [лавлахын CRUD](admin-reference-crud.md), [UI kit](../ui/admin-ui-kit.md).

## Урсгал

- Нэг цагаан ажлын хэсэгт зүүн талд **Брэнд**, баруун талд **Загвар** байна.
- Брэнд сонгоход зөвхөн тухайн брэндийн загварууд ачаална. Брэнд солиход өмнөх загварууд болон хоцорч ирсэн хариуг шинэ жагсаалтад харуулахгүй.
- Брэнд сонгоогүй үед загвар нэмэх, шинэчлэх боломжгүй. Идэвхгүй брэндийн загваруудыг үзэж/засаж болно; шинээр загвар нэмэхгүй.
- Багана бүр нэмэх/шинэчлэх товч, loading, error/retry, empty төлөв, өөрийн босоо scroll болон нийт бүртгэлийн тоотой. Бүх хуудсыг 100-аар дараалан уншина.
- Мөр бүрийн гурван цэгтэй menu дотор засах, устгах үйлдэл байна. Menu нээхэд брэндийн сонголт солигдохгүй. Устгахдаа баталгаажуулна; ашиглагдаж буй бүртгэлийн хориг хэвээр.
- Сонголт `brandId` URL query-д хадгалагдана; refresh, Back/Forward үед сэргээнэ. Сонгосон брэнд устсан/олдсонгүй бол загварын багана сонголт хүлээсэн төлөвт шилжинэ.

## Form

- Брэнд нэмэхэд харьяаллын талбар байхгүй; үүссэн брэндийг автоматаар сонгоно.
- Загвар нэмэхэд form нээсэн үеийн брэнд автоматаар бөглөгдөж, өөрчлөх боломжгүй байна. `brandId` нь create body-д орно.
- Загвар засахад брэнд өөрчлөхгүй, PATCH body-д `brandId` илгээхгүй.
- Нийтлэг `ReferenceForm`, Mantine `useForm`, DTI validation болон алдааны мессежийг ашиглана. Хадгалах үед давхар submit, цонх хаахаас сэргийлнэ; алдаанд бөглөсөн утгууд хадгалагдана.
- Амжилттай өөрчлөлтийн дараа холбогдох баганыг дахин уншина. Нэмэлт cache байхгүй.

## Харагдац

- Mantine `sm` (одоогоор 768px)-ээс доош нэг багана болж, Брэнд → Загвар дарааллаар доош байрлана. Mobile гарчиг саарал дэвсгэр, 3px дээд заагтай; хэсэг хооронд 24px зайтай.
- 768px-ээс эхлээд хоёр багана байна. Хэт нарийн ажлын хэсэгт зөвхөн багануудын хүрээнд хөндлөн гүйнэ; бүтэн хуудас overflow үүсгэхгүй.
- Автомашинтай дундаа `references/hierarchy/HierarchyColumn` болон `useHierarchyColumn` ашиглана. Layout/зааг/сонголт нь Mantine component/props-оор шийдэгдэнэ, шинэ CSS class/media query байхгүй.
- Устгах цонхны зайгүй урт нэрийг бүтнээр нь багтаах `overflowWrap` exception болон нийтлэг `PageBody`/form-ийн дүрэм автомашинтай ижил.

## Өөрчлөлтийн зааг

Өмнөх `/references/tire-brands`, `/references/tire-models` тусдаа URL-ууд ажиллана. Лавлахын нүүрээс шинэ нэгтгэсэн хуудсанд орно. API contract, backend service, DB schema/migration, бодит өгөгдөл, Userly/ACL бодлогыг өөрчлөхгүй.

## Шалгалт

App-ийн 50 тест, TypeScript check болон build тэнцсэн. Playwright/Edge дээр 320/767px нэг багана, 768/1440px хоёр багана, тусдаа scroll, parent filter/prefill, menu, идэвхгүй брэнд, URL refresh/Back, тусдаа refresh, error/retry болон хоцорсон хариуны хамгаалалтыг шалгасан. Брэнд/загварын create/update/delete, immutable `brandId`, давхардсан нэр болон ашиглагдаж буй брэндийн устгах хоригийг mocked API-тай шалгасан; бодит өгөгдөлд бичээгүй. Local API-аас автомашин болон дугуйн лавлах унших шалгалт хийсэн.
