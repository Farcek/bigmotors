- Хэрэглэгч: Admin ажилтан.
- URL: `/references/colors`; Лавлах → Өнгө.
- Хамаарал: [UI kit](../ui/admin-ui-kit.md), [form/cache шийдвэр](../adr/0028-use-mantine-form-without-query-cache.md), [ажиллуулах заавар](../operations/sysop-app.md).

## Урсгал ба талбар

Жагсаалтаас нэмэх/засах modal нээнэ. Устгах үйлдэл баталгаажуулалттай. Form нь Mantine `useForm`, хүсэлт нь `@napp/dti-client` болон `Colors` contract ашиглана.

| Талбар | Дүрэм |
| --- | --- |
| Нэр | Заавал, trim хийсний дараа 1–255 тэмдэгт |
| HEX код | Сонголттой, `#RRGGBB`; өнгө сонгогчтой, хоосон бол `null` |
| Тайлбар | Сонголттой, 512 тэмдэгт; хоосон бол `null` |
| Дараалал | Бүхэл тоо, -2147483648–2147483647, анхны утга 0 |
| Идэвхтэй | Switch, шинэ бүртгэлд true |

ID болон үүсгэсэн/зассан огноог сервер хариуцна; form-оос илгээхгүй. Validation нь DTI schema-г ашиглаж, API-ийн дүрмийг сулруулахгүй.

## Жагсаалт ба төлөв

- Өнгөний нэр, тайлбар, swatch, HEX, дараалал, төлөв болон мөрийн үйлдлүүдийг харуулна.
- Идэвхтэй/идэвхгүй шүүлт, хуудас нь `isActive`, `page` URL query-д байна. Шүүлт өөрчлөхөд эхний хуудас руу буцна.
- Хуудсанд 20 мөр. API-аас 21 мөр авч дараах хуудас байгаа эсэхийг тогтооно. API нийт тоо өгөхгүй тул нийт хуудас/нийт мөрийн тоо харуулахгүй.
- Серверийн `sortOrder`, `name`, `id` өсөх эрэмбийг дагана. Одоогийн contract-д байхгүй хайлт/эрэмбийн параметр нэмээгүй.
- Амжилттай mutation бүрийн дараа жагсаалтыг дахин уншина. Query cache, optimistic update, автомат retry болон persistence байхгүй.
- Loading, хоосон, алдаа/дахин оролдох, амжилтын мэдэгдэлтэй. Хуучирсан list хүсэлтийг abort хийж, хариуг нь үл тооцно.
- Хадгалж байх үед давхар submit болон modal хаахыг хориглоно. Алдаа гарвал form утга хадгалагдана.
- Давхардсан нэрийг нэрийн талбарт харуулна. Ашиглагдаж буй өнгийг устгах API алдаа гарвал идэвхгүй болгох санал харуулна.

## Хүрээ ба шалгуур

Зөвхөн colors UI; бусад лавлахын CRUD, API/schema/migration өөрчлөлт ороогүй. Userly/ACL-ийн одоогийн түр bypass-ийг өөрчлөөгүй; production нэвтрэлт/эрхийн хамгаалалт бэлэн гэсэн үг биш.

Нэмэх, жагсаах, засах, устгах нь байгаа HTTP contract-ыг ашиглана. Гар утсанд form нэг багана, хүснэгт өөрийн scroll хэсэгт байна. Unit тест нь талбарын хил, payload, алдааны mapping болон URL query-г шалгана; API HTTP тест нь тусгаарласан DB ашиглана.
