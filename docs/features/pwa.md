# Public website-ийн PWA боломж

- Огноо: 2026-09-08
- Төлөв: PWA дэмжих шаардлага батлагдсан; нарийвчилсан хүрээ нээлттэй
- Холбоотой шийдвэр: [Next.js болон Node.js 24](../adr/0002-use-nextjs-and-nodejs-24.md)

## Зорилго ба хэрэглэгч

Public website-ийг үзэх хэрэглэгчдэд PWA боломж олгоно.

## Батлагдсан хүрээ

- PWA дэмжлэгийг `website` хэсэгт хэрэгжүүлнэ.
- Website нь Next.js ашиглана.

## Хараахан батлаагүй боломжууд

- Төхөөрөмжид суулгах хэрэглэгчийн урсгал, дэмжих browser болон төхөөрөмж
- Offline үед харуулах хуудас, каталог, зураг болон хадгалах өгөгдлийн хэмжээ
- Cache шинэчлэх дүрэм, үнэ болон автомашины төлөвийн хуучирсан мэдээллийг ялгаж харуулах арга
- Push notification, background sync
- Admin frontend-д PWA дэмжлэг нэмэх эсэх

Эдгээрийг PWA гэсэн ерөнхий шаардлагаас автоматаар батлагдсан боломж гэж үзэхгүй.

## Хүлээн авах шалгуур

Нарийвчилсан шалгуурыг дэмжих browser, суулгах урсгал, offline болон шинэчлэлтийн бодлого тодорхой болсны дараа бичнэ. Одоогоор зөвхөн PWA дэмжих шаардлага батлагдсан бөгөөд хэрэгжүүлэлт дууссан гэж үзэх үндэс биш.

## Нээлттэй асуултууд

- Эхний хувилбарын PWA яг ямар хэрэглэгчийн урсгалыг дэмжих вэ?
- Offline өгөгдөл шаардлагатай юу, шаардлагатай бол юу хадгалах вэ?
- Шинэ хувилбар гарах болон сүлжээ тасрах үед ямар үйлдэл үзүүлэх вэ?
