# Автомашины public каталог

- Огноо: 2026-09-10
- Төлөв: Баталсан
- Үндэслэл: Хэрэглэгч UI зургуудыг хэлэлцсэний дараа нийтэд харуулах талбар, хайлт, шүүлт, эрэмбийн саналыг баталсан
- Холбоотой баримт: [Автомашины талбарууд](vehicle-fields.md), [Лавлах ба тогтмол сонголт](../db/vehicle-reference-data.md), [Бүтээгдэхүүний хүрээ](scope.md), [UI / UX](../ui/README.md)

## Зорилго ба хүрээ

Зочин BigMotors-ийн автомашинуудыг үзэх, хайх, шүүх, эрэмбэлэх, дэлгэрэнгүй мэдээлэл болон компанийн холбоо барих мэдээллийг авах боломжтой байна. Олон борлуулагчтай зарын сайт биш; сайтаар худалдахгүй, CRM-ийг тусдаа системээр боловсруулна.

Энэ баримт автомашины каталогт хамаарна. Сэлбэг, дугуйд [нийтлэг бүтээгдэхүүний дүрэм](product-common-rules.md)-ийн карт, үнэ/шүүлт/эрэмбийн зарчим үйлчилнэ; автомашины онцлог public/filter талбаруудыг шууд хуулбарлахгүй. Талбарын бөглөх шаардлага, тоон хязгаар, төлөв шилжилт нь [бүртгэлийн баримтад](vehicle-fields.md) хэвээр байна.

## Жагсаалтын карт

| Мэдээлэл | Эх талбар ба харуулах дүрэм |
| --- | --- |
| Зураг | `item_image_id`; бөглөөгүй бол `main_image_id` |
| Гарчиг | `item_title`; бөглөөгүй бол `title` |
| Товч тайлбар | `item_desc`; бөглөөгүй бол `description`; хоёул хоосон бол харуулахгүй |
| Гол үзүүлэлт | Үйлдвэрлэсэн он V05, гүйлт V18, түлш V09, хурдны хайрцаг V11 |
| Үнэ | Үнэ V21, валют V22, үнэ харуулах хэлбэр V23: бүтэн дүн, жишээ нь `84,500,000 ₮`; эсвэл "Үнэ асуух" |
| Тэмдэглэгээ | Шинэ/хуучин V17 болон ирэлтийн төлөв V25 |
| Үйлдэл | Карт дээр дарахад тухайн машины дэлгэрэнгүйг нээнэ |

Үнийн дүн нь форматын жишээ болохоос бодит машины үнэ биш. Item талбаруудын fallback нь зөвхөн render дээр үйлчилнэ, DB-д хуулж хадгалахгүй. Бусад сонголттой үзүүлэлт хоосон бол тухайн үзүүлэлтийг харуулахгүй; `0` эсвэл зохиомол утгаар орлуулахгүй. [Нийтлэг дүрэм](product-common-rules.md)-ийг баримтална.

Үндсэн жагсаалтад зөвхөн `published + available` машин орно. Зарагдсан машин орохгүй; нийтлэгдсэн дэлгэрэнгүй хуудсыг хадгалах дүрмийг [төлөвийн шаардлага](vehicle-fields.md)-аар мөрдөнө.

## Дэлгэрэнгүй хуудас

| Хэсэг | Нийтэд харуулах мэдээлэл |
| --- | --- |
| Үндсэн | Гарчиг V01, үндсэн зураг V27, нэмэлт зураг ба дараалал V28, үнэ V21, валют V22, үнэ харуулах хэлбэр V23, шинэ/хуучин V17, ирэлтийн төлөв V25 |
| Машины мэдээлэл | Марк V02, загвар V03, комплектаци V04, үйлдвэрлэсэн он V05, Монголд орж ирсэн он V06, кузов V08 |
| Техникийн үзүүлэлт | Түлш V09, хөдөлгүүрийн багтаамж V10, хурдны хайрцаг V11, хөтлөгч V12, жолооны байрлал V13, гүйлт V18, суудал V16 |
| Өнгө, нөхцөл | Гадна өнгө V14, салоны өнгө V15, нөхцөл байдлын тайлбар V20 |
| Үндсэн агуулга | Rich text `content` V30; дэлгэрэнгүй танилцуулгын үндсэн агуулга |
| Товч тайлбар | `description`; short description, SEO, share-д ашиглана |
| Нэмэлт | Тоноглол V29, зээлээр авах боломж V26 |
| Холбоо барих | Салбар V19 байгаа үед салбарын мэдээлэл; компанийн баталгаажсан утас |
| Зарагдсан машин | V24 нь `sold` бөгөөд нийтлэгдсэн бол "Зарагдсан" тэмдэглэгээ |

Сонголттой мэдээллийг байгаа үед харуулна. Хамаарахгүй мэдээллийг зохиомлоор нөхөхгүй. Зээлээр авах боломж нь зөвхөн мэдээлэл; хүсэлт болон тооцоолуур нэмэхгүй. Үнэ асуух горимд дотоодод үнэ оруулсан байсан ч үнийн дүн нийтэд харагдахгүй.

Машинд өмнө сонгосон лавлах идэвхгүй болсон ч нэрийг нь хэвийн харуулна; "идэвхгүй" тэмдэглэгээ зөвхөн admin-д байна. Лавлахын идэвхгүй байдал машиныг нийтээс автоматаар нуухгүй. Засах/дахин нийтлэх дүрмийг [лавлахын баримтад](../db/vehicle-reference-data.md) хөтөлнө.

### Нийтэд харуулахгүй мэдээлэл

- VIN / арлын дугаар V07: эхний хувилбарт зөвхөн admin-д харуулна. Давхардал зөвшөөрсөн, тусгай шалгалтгүй text талбар хэвээр.
- Дотоод тэмдэглэл V33: зөвхөн admin-д, нийтэд харуулахгүй.
- Нийтлэлийн төлөв V31, онцлох эсэх V32: удирдлагын мэдээлэл; машины үзүүлэлтийн мөр болгож харуулахгүй. Нийтлэлийн төлөвөөр нийтэд нээлттэй эсэхийг шийдэх дүрэм хэвээр.

## Хайлт ба шүүлт

| Байрлал | Талбарууд |
| --- | --- |
| Текст хайлт | Гарчиг V01, `item_title`, марк V02, загвар V03, комплектаци V04 |
| Үндсэн шүүлт | Марк V02, загвар V03, үнэ V21 доод/дээд, үйлдвэрлэсэн он V05 доод/дээд |
| Дэлгэрэнгүй шүүлт | Шинэ/хуучин V17, кузов V08, түлш V09, хурдны хайрцаг V11, хөтлөгч V12, жолооны байрлал V13, гүйлт V18 доод/дээд, ирэлтийн төлөв V25, салбар V19 |

- Марк сонгосны дараа тухайн маркын загваруудыг харуулна. Марк солиход тохирохгүй загварын сонголтыг цэвэрлэнэ.
- Өөр талбарын шүүлтүүдийг `AND` нөхцөлөөр хослуулна.
- Үнийн хүрээ сонгосон үед "Үнэ асуух" машиныг үр дүнд оруулахгүй; дотоодод үнэ оруулсан эсэхээс үл хамаарна.
- Шүүж буй талбар нь хоосон машин тухайн шүүлтэд таарахгүй.
- Сонгосон шүүлтүүд, үр дүнгийн тоо, шүүлт тус бүрийг арилгах болон бүгдийг цэвэрлэх үйлдэл байна.
- Хайлт, шүүлт, эрэмбэ нь үндсэн жагсаалтын `published + available` хязгаарлалтыг өөрчлөхгүй.

## Эрэмбэ

| Сонголт | Дүрэм |
| --- | --- |
| Сүүлд нийтэлсэн эхэнд | Анхны эрэмбэ; анх нийтэлсэн огноогоор буурах. Засвар хийснээр дээшлэхгүй |
| Үнэ өсөх | Нийтэд харуулах үнийн дүнгээр өсөх; "Үнэ асуух" машинууд сүүлд |
| Үнэ буурах | Нийтэд харуулах үнийн дүнгээр буурах; "Үнэ асуух" машинууд мөн сүүлд |
| Үйлдвэрлэсэн он шинэ эхэнд | Үйлдвэрлэсэн оноор буурах |
| Гүйлт бага эхэнд | Гүйлтээр өсөх; гүйлт тодорхойгүй машинууд сүүлд |

Анх нийтэлсэн огноог эрэмбэд ашиглах шаардлага нь бүртгэлийн 33 талбарыг солихгүй. Огнооны DB багана, хадгалах хэлбэр болон ижил утгатай машинуудын хоёрдогч эрэмбийг тусад нь тогтооно.

## UI лавлагааны зааг

Хэрэглэгчийн оруулсан дэлгэрэнгүй болон жагсаалтын хоёр screenshot нь лавлагаа. Тэдгээрийн өнгө, брэнд, бүх товч, жишээ агуулгыг батлагдсан шаардлага гэж үзэхгүй.

- BigMotors-ийн өөрийн каталогт тохируулна; гарчиг, зураг, үйлдвэрлэсэн он, загвар нь тухайн машины мэдээлэлтэй нийцнэ.
- "Марк / Загвар" нэршил хэрэглэнэ. Жолооны байрлалыг "Зүүн / Баруун", хөтлөгчийг баталсан сонголтоор харуулна; "Буруу жолоо", "Мосттой" гэж орлуулахгүй.
- Үйлдвэрлэсэн улс, баталгаа зэрэг баталгаажаагүй нэмэлт мэдээллийг одоохондоо нэмэхгүй.
- Хувийн борлуулагчийн profile, verified dealer, хүсэлтийн form, зээлийн тооцоолуур, compare, хадгалах, notification, public account болон видео боломжийг зургаас шууд хэрэгжүүлэхгүй. Нэмэх бол тусад нь батална.
- Олон төрлийн баганын тоо сонгох удирдлага хэрэггүй; жагсаалтын багана дэлгэцийн хэмжээнд автоматаар тохирно.

## Хүлээн авах шалгуур

1. Карт батлагдсан `item_*` мэдээлэл, гол үзүүлэлт, үнэ болон тэмдэглэгээг харуулж, зөв машины дэлгэрэнгүйд шилжинэ.
2. Хоосон сонголттой үзүүлэлтийг зохиомол утгаар харуулахгүй; арлын дугаар болон дотоод тэмдэглэл public хуудас дээр харагдахгүй.
3. Үндсэн жагсаалтад `published + available` машин л орно. Зарагдсан, нуусан, ноорог эсвэл архивласан машин хайлт, шүүлтээр жагсаалтад орохгүй.
4. Өөр марк сонгоход өмнөх тохирохгүй загвар цэвэрлэгдэж, шинэ маркын загварууд харагдана.
5. Хослуулсан шүүлтийн бүх нөхцөлийг хангасан машинууд үр дүнд орно; идэвхтэй шүүлтийн талбар хоосон машин орохгүй.
6. Үнийн хүрээтэй хайлтад "Үнэ асуух" машин орохгүй. Үнийн эрэмбийн хоёр чиглэлд эдгээр машинууд сүүлд байна.
7. Шүүлт тус бүрийг арилгах болон бүгдийг цэвэрлэхэд үр дүн, үр дүнгийн тоо нийцэж шинэчлэгдэнэ.
8. Анхны эрэмбэ анх нийтэлсэн огноог ашиглана; мэдээлэл зассанаар машин дээшлэхгүй. Гүйлтийн эрэмбэд тодорхойгүй гүйлт сүүлд байна.
9. Дэлгэцийн хэмжээнд багана автоматаар тохирно; хэрэглэгчээс баганын тоо сонгох шаардлагагүй.

## Дараа шийдэх зүйлс

- Текст хайлтын яг/хэсэгчилсэн тохирол, том/жижиг үсэг, олон үг болон бичгийн хувилбарын дүрэм.
- Нэг шүүлтэд олон утга сонгох эсэх, тэр тохиолдлын хослуулах нөхцөл.
- Шүүлтийн хүрээний алхам, хязгаар, доод/дээд утгын шалгалт, хоосон үр дүн болон алдааны UI.
- Хуудаслалт, нэг хуудсан дахь тоо, ижил утгын хоёрдогч эрэмбэ, URL-д хайлт/шүүлт/эрэмбэ хадгалах эсэх.
- Брэнд, theme, typography, responsive breakpoint, зургийн хэмжээ болон дэлгэцийн эцсийн зохиомж.
- Салбарын нийтэд харуулах нарийвчилсан мэдээлэл болон компанийн бодит утас.

Зөвхөн шаардлага батлагдсан. UI, код, API contract, DB schema хэрэгжүүлээгүй; tech spec task-уудын төлөвийг энэ шийдвэрээр өөрчлөхгүй.
