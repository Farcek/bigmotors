# Сэлбэг хэрэгслийн бүртгэлийн талбарууд

- Огноо: 2026-09-10
- Төлөв: Санал болгосон; талбарын жагсаалтыг баталгаажуулах
- Холбоотой баримт: [Бүтээгдэхүүний хүрээ](scope.md), [DB хэлэлцүүлэг](../db/README.md), [Нийтлэг item талбарын дүрэм](vehicle-fields.md#product-ийн-жагсаалтын-талбарууд)

## Зорилго ба зааг

Сэлбэгийг каталогт бүртгэх, танилцуулах болон admin-аас мэдээллийг удирдахад ямар талбар хэрэгтэйг тодорхойлох санал. Нэг бүртгэл ижил бүтээгдэхүүний төрлийг төлөөлж, олон ширхэг байж болох батлагдсан зарчмыг баримтална. Дугуй нь тусдаа үндсэн бүтээгдэхүүн тул энэ жагсаалтад нэгтгэхгүй.

Доорх 25 талбар нь санал; заавал бөглөх, нийтэд харагдах, шүүлтэд ашиглах дүрмийг дараа батална. DB хүснэгт, багана, constraint болон API contract тогтоохгүй. Product-ийн өмнө батлагдсан `item_*` талбарууд болон тэдгээрийн нийтлэх дүрэм хэвээр.

## 1. Үндсэн мэдээлэл

| ID | Талбар | Утга, тайлбар |
| --- | --- | --- |
| P01 | Бүтээгдэхүүний нэр / гарчиг | Сэлбэгийн үндсэн нэр; жагсаалтын `item_title`-аас тусдаа |
| P02 | Үндсэн ангилал | Жишээ: хөдөлгүүр, явах эд анги, цахилгаан, кузов, дагалдах хэрэгсэл |
| P03 | Дэд ангилал | Тухайн үндсэн ангиллын доторх төрөл; бүрэн жагсаалтыг дараа тогтооно |
| P04 | Сэлбэгийн үйлдвэрлэгч / брэнд | Сэлбэгийг үйлдвэрлэсэн брэнд; тохирох автомашины марк биш |
| P05 | Бүтээгдэхүүний загвар / цуврал | Үйлдвэрлэгчийн бүтээгдэхүүний нэрлэсэн загвар, байвал |
| P06 | Нөхцөл | Жишээ: шинэ, хуучин, сэргээн засварласан; эцсийн сонголтыг дараа батална |

## 2. Код ба дугаар

| ID | Талбар | Утга, тайлбар |
| --- | --- | --- |
| P07 | Дотоод SKU | BigMotors-ийн дотоод бүтээгдэхүүний код |
| P08 | Үйлдвэрлэгчийн part number | Тухайн сэлбэгт үйлдвэрлэгчээс өгсөн эд ангийн дугаар |
| P09 | OEM лавлах дугаарууд | Байвал холбогдох эх эд ангийн дугаарууд; олон утгатай байж болно |

SKU, part number, OEM лавлах дугаарыг нэг талбарт холихгүй байх саналтай. Дугаар байгаа нь бүтээгдэхүүнийг оригинал гэж автоматаар батлахгүй. Дугаарын формат, үйлдвэрлэгчийн хүрээнд давхцах дүрэм болон ижил бүтээгдэхүүнийг ялгах түлхүүрийг дараа шийднэ.

## 3. Нийцэл ба техникийн мэдээлэл

| ID | Талбар | Утга, тайлбар |
| --- | --- | --- |
| P10 | Тохирох автомашины жагсаалт | Нэг сэлбэг олон машины хувилбарт тохирч болох тул давтагдах мэдээлэл байна |
| P11 | Суурилуулах байрлал | Жишээ: урд/хойд, зүүн/баруун; зөвхөн хамаарах сэлбэгт |
| P12 | Техникийн үзүүлэлтүүд | Ангилалд тохирох хэмжээ, материал, хүчдэл зэрэг нэр, утга, шаардлагатай нэгж |

### Тохирох автомашины нэг бичлэгийн санал

| Талбар | Тайлбар |
| --- | --- |
| Автомашины үйлдвэрлэгч / марк | Тохирох машины марк |
| Загвар | Тохирох машины загвар |
| Үе / кузовын код | Байвал нийцлийг илүү нарийвчлах мэдээлэл |
| Үйлдвэрлэсэн оны эхлэл | Тохирох үйлдвэрлэлийн хугацааны эхлэл |
| Үйлдвэрлэсэн оны төгсгөл | Тохирох үйлдвэрлэлийн хугацааны төгсгөл |
| Хөдөлгүүр / хөдөлгүүрийн код | Нийцэл хөдөлгүүрээс хамаарах үед |
| Нийцлийн тайлбар | Нэмэлт нөхцөл болон баталгаажуулах шаардлага |

Энэ жагсаалт нь каталогт байгаа нэг бодит автомашинтай заавал холбох гэсэн үг биш; автомашины загвар/хувилбарын нийцлийг илэрхийлнэ. Марк, загвар, он зэргийг тус тусад нь холбоогүй жагсаалт болговол буруу хослол үүсэх тул нэг нийцлийн бичлэгт хамтад нь хадгалах саналтай.

Хоосон нийцэл нь бүх машинд тохирно гэсэн үг биш. Тодорхойгүй он, хөдөлгүүрийн хүрээг таамгаар өргөжүүлэхгүй. Universal бүтээгдэхүүн болон нийцэл нь тодорхойгүй бүтээгдэхүүнийг хэрхэн ялгахыг дараа батална. Энэ санал автомат fitment шалгагч эсвэл гаднын каталогийн интеграц нэмэхгүй.

## 4. Үнэ, нэгж ба бэлэн байдал

| ID | Талбар | Утга, тайлбар |
| --- | --- | --- |
| P13 | Үнэ | Тухайн бүтээгдэхүүний заасан нэгжийн үнэ |
| P14 | Валют | Үнийн валют |
| P15 | Үнэ харуулах хэлбэр | Үнэ харуулах / үнэ асуух; сэлбэгийн нөхцөлтэй шаардлагыг дараа батална |
| P16 | Үнийн нэгж | Үнэ нэг ширхэг, хос эсвэл иж бүрдлийн алинд хамаарахыг тодорхойлно |
| P17 | Савлагаа / иж бүрдлийн агуулга | Байвал хэдэн ширхэг, ямар зүйлс багтахыг тайлбарлана; агуулахын үлдэгдэл биш |
| P18 | Бэлэн байдлын төлөв | Жишээ: бэлэн, түр дууссан, ирэх; эцсийн сонголт болон утгыг дараа батална |
| P19 | Байршил / салбар | Байгаа салбарын мэдээлэл; олон салбарын боломжийг тусад нь шийднэ |

Сэлбэгийн бүртгэл олон ширхэгийг төлөөлөх тул нэгийг борлуулсан нь бүх бүтээгдэхүүнийг зарагдсан гэж тэмдэглэх үндэслэл болохгүй. Бэлэн байдлыг нийтлэлийн төлөвөөс салгах саналтай.

Одоогоор `stock_quantity`, үлдэгдэл нэмэх/хасах хөдөлгөөн, нийлүүлэлт, захиалга болон төлбөрийн урсгал санал болгож буй талбарын хүрээнд ороогүй. Үлдэгдлийн тоог хөтлөх эсэхийг тусад нь батална; дээрх нэгж/савлагааны мэдээлэл нь энэ шийдвэрийг орлохгүй.

## Нийтлэг item талбарууд

Сэлбэгт мөн `item_title`, `item_desc`, `item_image` хэрэглэнэ. Нийтлэхэд гарчиг, зураг заавал, тайлбар сонголттой бөгөөд хоосон утгыг дэлгэрэнгүй мэдээллээс автоматаар орлуулахгүй гэсэн [өмнө батлагдсан дүрэм](vehicle-fields.md#product-ийн-жагсаалтын-талбарууд) хэвээр. Автомашины бусад заавал бөглөх нөхцөл болон default-ыг сэлбэгт автоматаар шилжүүлэхгүй.

## Дараагийн шийдвэрүүд

- Дээрх талбарын жагсаалтыг батлах, шаардлагагүй талбарыг хасах.
- Ноорог/нийтлэх үед заавал бөглөх эсэх, public харагдах байдал болон шүүлтийн хэрэглээ.
- Ижил сэлбэгийг брэнд, part number, байрлал, нөхцөл, савлагаагаар хэрхэн ялгах; ялгаатай хувилбаруудын бүртгэл.
- Ангилал, нөхцөл, бэлэн байдал, нийтлэлийн төлөвийн сонголт ба шилжилт.
- Нийцлийн мэдээллийн эх сурвалж, нарийвчлал, universal болон тодорхойгүй нөхцөлийн дүрэм.
- Үлдэгдлийн тоо хэрэгтэй эсэх, олон салбарын мэдээлэл болон үнийн нэгжийн дүрэм.

## Хүлээн авах шалгуурын санал

1. Сэлбэгийн брэнд, SKU, part number болон тохирох машины мэдээлэл хоорондоо ялгаатай байна.
2. Нэг сэлбэгт олон нийцлийн бичлэг бүртгэхэд марк/загвар/он/хөдөлгүүрийн нөхцөл хоорондоо холилдохгүй.
3. Үнэ ямар нэгжид хамаарах нь тодорхой байна; савлагааны агуулгыг үлдэгдлийн тоо гэж үзэхгүй.
4. Нийтлэг `item_*` талбарын батлагдсан дүрмийг хадгална.
5. Талбарын санал нь CRM, агуулахын систем, онлайн худалдаа эсвэл DB schema хэрэгжүүлэлт нэмэхгүй.
