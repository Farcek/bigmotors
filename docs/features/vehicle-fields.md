- Хүрээ: Автомашины батлагдсан 34 талбар болон product-ийн `description`, `item_title`, `item_desc`, `item_image_id`; V30 нь `content`
- Холбоотой баримт: [Бүтээгдэхүүний хүрээ](scope.md), [Нийтлэг дүрэм](product-common-rules.md), [Public каталог](vehicle-catalog.md), [DB тэмдэглэл](../db/README.md)

## YouTube видео (2026-09-13 нэмэлт)

- `youtubeUrl` / `vehicles.youtube_url`: нэг сонголттой text URL, 2048 хүртэл тэмдэгт; ноорог болон нийтлэхэд заавал биш. Хоослох үед NULL.
- Зөвхөн HTTPS YouTube видеоны холбоос: youtube.com, www.youtube.com, m.youtube.com watch/shorts/embed/live болон youtu.be богино холбоос. Channel/playlist-only, өөр host, credential болон өөр port зөвшөөрөхгүй.
- Input түвшинд video ID бүхий URL эсэхийг шалгана; видеоны бодит хүртээмжийг гадна хүсэлтээр шалгахгүй. Нэг талбар тул олон видео/upload байхгүй.
- Admin-ийн Зураг / Видео tab-д засна; public card дээр тусдаа YouTube холбоос болно. Автоматаар тоглуулахгүй.

## Зорилго ба зааг

Нэг бодит автомашинд ямар мэдээлэл бүртгэх болон ноорог/нийтлэх үед хэрхэн бөглөхийг хамтад нь тодорхойлно. Ижил марк, загвар, онтой хоёр машин тусдаа бүртгэлтэй байна. Талбарын жагсаалт, бөглөх шаардлага болон доорх тоон талбарын дүрэм батлагдсан. DB лавлахын жишээ утгууд нь эцсийн seed жагсаалт биш. Enum/const-ийн батлагдсан утга, утгын кодыг [лавлахын бүртгэл](../db/vehicle-reference-data.md)-д хөтөлнө. Энэ баримт API contract, UI зохиомж, DB schema, public талбарын бүрэн жагсаалт болон шүүлтийг тогтоохгүй. Сэлбэг/дугуйн тусгай талбаруудын бөглөх шаардлагыг энд шийдэхгүй.

## Үндсэн зарчим

- Ноорог хадгалахад хэрэглэгч зөвхөн үндсэн гарчгийг заавал бөглөнө. Нийтлэлийн төлөвийг ноорог, онцлох эсэхийг үгүй гэж систем анх тохируулна.
- Нийтлэхэд доорх заавал болон нөхцөлтэй шаардлагуудыг хангана. Нийтлэгдсэн мэдээллийг засаж хадгалахад мөн адил шалгана. Шаардлагатай мэдээллийг хасах бол эхлээд нийтэд харагдахгүй төлөвт шилжүүлнэ.
- Шаардлагатай мэдээлэл тодорхойгүй бол ноорог хэвээр хадгална; нийтлэхийн тулд зохиомол утга бөглөхгүй.
- Хамаарахгүй болон тодорхойгүй утгыг `0`, хоосон текст эсвэл худал `үгүй` утгаар орлуулахгүй. Заавал текстэд зөвхөн зай бичсэнийг бөглөсөнд тооцохгүй.
- Бөглөх шаардлага нь public харуулах шаардлага биш. Нийтэд харуулах талбаруудыг [public каталогийн баримтад](vehicle-catalog.md) баталсан; VIN/арлын дугаар болон дотоод тэмдэглэл зөвхөн admin-д харагдана.

Тэмдэглэгээ: **Заавал** = утгатай байх; **Сонголттой** = хоосон байж болно; **Нөхцөлтэй** = тайлбарт заасан үед заавал; **Систем** = хэрэглэгч заавал бөглөхгүй, систем тохируулна.

## Текстийн талбарын дүрэм

2026-09-10: Гарчиг/`title` талбарууд хамгийн ихдээ 255 тэмдэгт, `desc` буюу товч тайлбарууд хамгийн ихдээ 512 тэмдэгт байна. Машины дэлгэрэнгүй тайлбарт rich text editor ашиглана.

| Талбар | Хэлбэр | Дээд урт |
| --- | --- | --- |
| Үндсэн гарчиг V01 | Энгийн text | 255 тэмдэгт |
| `item_title` | Энгийн text | 255 тэмдэгт |
| Зураг бүрийн `title` | Энгийн text | 255 тэмдэгт |
| `item_desc` | Энгийн text | 512 тэмдэгт |
| `description` | Энгийн text; short description, SEO, share | 512 тэмдэгт |
| Нөхцөл байдлын тайлбар V20 | Энгийн text | 512 тэмдэгт |
| Зураг бүрийн тайлбар | Энгийн text | 512 тэмдэгт |
| Үндсэн агуулга `content` V30 | Rich text editor | Тусдаа; 512 тэмдэгтээр хязгаарлаагүй |

Item талбаруудын шинэчилсэн бөглөх шаардлага, render fallback-ийг доорх хүснэгт болон [нийтлэг дүрэм](product-common-rules.md)-ээс харна. `description` нь ноорог болон нийтлэхэд сонголттой. Утга оруулсан үед дээд уртын шалгалт ноорог болон нийтлэхэд адил үйлчилнэ; хэтэрсэн текстийг автоматаар тасалж хадгалахгүй. Энэ нь бүх text талбарт нийтлэг 255/512 хязгаар тавина гэсэн үг биш: арлын дугаарын тусгай шалгалтгүй дүрэм болон дотоод тэмдэглэлийн зааг өөрчлөгдөхгүй.

`content`-ийг HTML хэлбэрээр DB-ийн `text` баганад хадгална, nullable байна. Rich text editor-ийн сан, toolbar боломжууд, HTML sanitization/аюулгүй харуулах механизм болон дэлгэрэнгүй агуулгын тусдаа хязгаарыг дараа тогтооно. Editor ашиглах шийдвэр нь зураг/video embed зэрэг нэмэлт боломжийг автоматаар батлахгүй.

## Зургийн бүртгэлийн дүрэм

2026-09-10: Хэрэглэгч автомашины зургийн дараах шаардлагыг баталсан.

- Нэг машинд оруулах зургийн тоонд дээд хязгаар тавихгүй.
- Зураг бүрд `title` (гарчиг), тайлбар оруулах боломжтой байна. Хоёул сонголттой; зургийн нэмэлт мэдээлэл болохоос машины үндсэн гарчиг, `item_title`, `item_desc`-ийг орлохгүй.
- Зургийн форматыг JPEG/PNG/WebP зэрэг тогтсон жагсаалтаар хязгаарлахгүй. Энэ нь зураг биш дурын файлыг зөвшөөрнө гэсэн үг биш.
- Upload хийсэн эх зургийг өөрчлөлтгүй хадгална. Эх файлыг автоматаар шахсан, хэмжээг өөрчилсөн эсвэл өөр форматад хөрвүүлсэн файлаар солихгүй.
- Үндсэн зураг V27 (`main_image_id`) нийтлэхэд заавал, нэмэлт зургууд V28 сонголттой. `item_image_id` сонголттой; бөглөөгүй бол render дээр үндсэн зургийг авна.

Зураг бүрийн гарчиг, тайлбар нь зургийн түвшний мэдээлэл; автомашины үндсэн 33 талбарт тусдаа мөр нэмэхгүй. Зургийн metadata-ийн DB бүтэц болон тайлбарын identifier-ийг schema боловсруулах үед тогтооно.

Браузер зураг харуулж чадах эсэхийг шалгахгүй. Upload хийсэн эх зургийг энгийн байдлаар харуулахад ашиглана; браузер харуулж чадахгүй байхыг хүлээн зөвшөөрнө. Үүнээс болж upload, хадгалах эсвэл нийтлэхийг хориглохгүй; тусгай preview, хөрвүүлэлт эсвэл орлуулах зураг шаардахгүй. Энэ дүрэм үндсэн зураг, нэмэлт зураг болон `item_image`-д адил хамаарна. Upload дууссан зураг сонгох өмнөх шаардлага хэвээр.

Файлын хэмжээ, upload/ашиглалт болон устгах дүрэм [file management](file-management.md)-д батлагдсан. Пиксел/decode шалгалт нэмэхгүй; аюулгүй serve/access-ийн нарийвчлал тусдаа нээлттэй. Зургийн гарчиг, тайлбарыг нийтэд хаана харуулах эсэх хараахан тогтоогүй; урт нь дээрх текстийн дүрмээр батлагдсан. Браузерын форматын дэмжлэгийг шалгах болон тусгай preview боловсруулах нь нээлттэй task биш, одоогийн хүрээнд шаардахгүй.

| --- | --- | --- |
| V05 Үйлдвэрлэсэн он | Он | `1900`-аас тухайн он хүртэл |
| V06 Монголд орж ирсэн он | Он | `1900`-аас тухайн он хүртэл; үйлдвэрлэсэн оноос өмнө байж болохгүй |
| V10 Хөдөлгүүрийн багтаамж | `cc` | `1–30,000` |
| V18 Явсан километр | `км` | `0–9,999,999` |
| V16 Суудлын тоо | Суудал | `1–100`; жолоочийг багтаасан нийт суудал |
| V21 Үнэ | `MNT` | `1–99,999,999,999` |

- Тухайн он нь шалгалт хийх үеийн он; `2026` гэж тогтмол хязгаарлахгүй. Үйлдвэрлэсэн он нь model year биш, бодит үйлдвэрлэсэн он байна.
- Импортын он болон үйлдвэрлэсэн он хоёулаа бөглөгдсөн үед хооронд нь шалгана.
- Хоосон утга нь `0` биш. Мэдээлэл тодорхойгүй бол хоосон үлдээнэ; өмнө баталсан заавал болон нөхцөлтэй шаардлага хэвээр.
- Ноорогт сонголттой талбарыг хоосон хадгалж болно. Утга оруулсан бол дээрх шалгалт ноорог хадгалахад ч үйлчилнэ.
- Бутархай утгыг автоматаар бүхэл болгохгүй; засаж оруулахыг шаардана. Хязгаараас гарсан утгыг хадгалахгүй.
- Гүйлт `0` байж болно. Шинэ машинд автоматаар `0` оноохгүй.
- Цэвэр цахилгаан машины хөдөлгүүрийн багтаамж хоосон байна; `0` гэж бөглөхгүй.
- Үнэ асуух горимд үнэ хоосон байж болно. Үнэ оруулсан бол мөн дээрх хязгаарт багтсан эерэг бүхэл тоо байна.
- Үнийг дэлгэцэд `125,000,000 ₮` гэх мэт бүлэглэж харуулна. Энэ нь зөвхөн формат харуулах жишээ, бодит машины үнэ биш; таслал нь тоон утгын хэсэг биш. Үнэ асуух горимд үнийн дүнг нийтэд харуулахгүй байх дүрэм хэвээр.

Эдгээр нь өгөгдөл оруулах алдаанаас сэргийлэх хязгаар болохоос каталогийн шүүлтийн хүрээ биш. Үнийн дүрмийг сэлбэг/дугуйд [нийтлэг дүрмээр](product-common-rules.md) ижил хэрэглэнэ; бусад тоон талбар, DB баганын төрөл, constraint-ийн хэрэгжүүлэлтийг шууд хуулбарлахгүй.

## Төлөв шилжилт ба харагдах байдал

2026-09-10: Доорх дүрмийг автомашины хүрээнд баталсан. Төлөвүүдийн утга, утгын кодыг [лавлахын бүртгэл](../db/vehicle-reference-data.md)-ээс авна. Дараагийн баталгаагаар нийтлэлийн төлөвийг сэлбэг/дугуйд [ижил хэрэглэнэ](product-common-rules.md); автомашины борлуулалтын/ирэлтийн төлөвийг шууд хуулбарлахгүй.

### Нийтлэлийн төлөв

| Шилжилт | Дүрэм |
| --- | --- |
| `draft -> published` | Нийтлэх шаардлагуудыг шалгана |
| `published -> hidden` | Сайтаас түр нууна |
| `hidden -> published` | Нийтлэх шаардлагуудыг дахин шалгана |
| `draft / hidden / published -> archived` | Идэвхтэй каталогоос гаргана; бүртгэлийг хадгална |
| `archived -> hidden` | Сэргээхэд шууд нийтлэхгүй |

Зөвхөн `published` машин нийтэд харагдана. `draft`, `hidden`, `archived` төлөвтэй машины мэдээлэл шууд холбоосоор ч нийтэд нээлттэй байхгүй. Архиваас сэргээсний дараа нийтлэх бол `hidden -> published` шилжилтийн шалгалтыг дамжина. Хүснэгтэд заагаагүй нийтлэлийн шилжилтийг зөвшөөрсөн гэж үзэхгүй.

### Борлуулалтын төлөв

- `available -> sold`: admin гараар тэмдэглэнэ.
- `sold -> available`: буруу тэмдэглэсэн эсвэл дахин худалдах болсон үед буцааж болно.
- Борлуулалтын төлөв өөрчлөхөд нийтлэлийн төлөв автоматаар өөрчлөгдөхгүй.

### Ирэлтийн төлөв

- Үндсэн дараалал: `expected -> in_transit -> in_stock`.
- Анх бүртгэхдээ бодит төлөвийг шууд сонгож болно; заавал `expected`-ээс эхлэхгүй.
- Алдаа засахын тулд ирэлтийн төлөвийг буцааж өөрчилж болно.
- Нийтлэгдсэн машиныг `in_stock` болгоход бодит байршил V34 заавал сонгоно. Компанийн салбар V19 үүнийг орлохгүй.

### Зарагдсан машины харагдах байдал

- `sold` машиныг үндсэн жагсаалтаас хасна.
- `sold + published` машины дэлгэрэнгүй хуудсыг өмнөх холбоосоор нь нээлттэй хадгалж, "Зарагдсан" тэмдэглэгээ харуулна.
- Бүрэн нуух шаардлагатай бол admin `hidden` болгоно. `sold` нь нийтлэлийн төлөвийн хязгаарлалтыг хүчингүй болгохгүй.
- Зарагдсан машины тусдаа жагсаалт, нүүр хуудасны хэсэг эсвэл санал болгох хэсэгт оруулах бодлогыг энэ шийдвэрээр батлаагүй.

Төлөв өөрчлөх нь өмнө баталсан нийтлэх болон нийтлэгдсэн мэдээлэл засах шалгалтыг алгасах үндэслэл болохгүй. Admin role бүрийн нарийвчилсан эрх, техникийн HTTP хариу болон cache шинэчлэх хэрэгжүүлэлтийг тусад нь шийднэ.

## Product-ийн жагсаалтын талбарууд

| Талбар | Ноорог | Нийтлэх | Тайлбар |
| --- | --- | --- | --- |
| `item_title` | Сонголттой | Сонголттой | 255 тэмдэгт хүртэл; бөглөөгүй бол render дээр `title` |
| `item_desc` | Сонголттой | Сонголттой | 512 тэмдэгт хүртэл; бөглөөгүй бол render дээр `description` |
| `item_image_id` | Сонголттой | Сонголттой | Бөглөөгүй бол render дээр `main_image_id`; сонгосон файл upload дууссан байна, браузерын дэмжлэг шалгахгүй |

Item талбар бүр хоосон үед харгалзах үндсэн талбараас render дээр автоматаар авна; бөглөсөн item утга давуу эрхтэй. Орлуулсан утгыг DB-д хуулж хадгалахгүй. `item_desc` нь `description` товч тайлбарыг ашиглана, `content` rich text-ийг ашиглахгүй. Хоёр товч тайлбар хоёул хоосон бол жагсаалтын тайлбар харуулахгүй.

Эдгээр гурван нийтлэг талбар болон бусад [нийтлэг бүтээгдэхүүний дүрэм](product-common-rules.md) бүх төрөлд үйлчилнэ. Сэлбэг/дугуйн онцлог талбарын нэмэлт нийтлэх шаардлагыг тусад нь шийднэ.

## Батлагдсан ялгаа

- 2026-09-10: [7 DB лавлах болон 10 enum/const бүлэг](../db/vehicle-reference-data.md), тэдгээрийг хөтлөх зарчим батлагдсан. Марк/загвар/хувилбар хамааралтай, өнгийн лавлах дундын, тоноглол олон сонголттой байна. Дараагийн баталгаагаар автомашины 10 тогтмол бүлгийн утга, утгын код, нэр болон зөвхөн `MNT` ашиглах дүрэм батлагдсан.

- Шинэ/хуучин, ирэлтийн, борлуулалтын болон нийтлэлийн төлөв нь тусдаа мэдээлэл байна. Нуусан нь зарагдсан гэсэн үг биш.
- Үнэ асуух гэсэн сонголт нь лавлах form, CRM холболт эсвэл захиалгын урсгалыг автоматаар батлахгүй.
- Зээлээр авах боломж нь мэдээллийн талбар; хүсэлт, төлбөрийн систем нэмэхгүй. [Нүүр хуудасны жишиг тооцоолуур](financing-calculator.md) нь тусдаа component бөгөөд энэ талбараас хамаарахгүй.
- Сайтаар худалдахгүй, CRM-ийг тусдаа системээр боловсруулах үндсэн хүрээ хэвээр.

## Дараа шийдэх зүйлс

- Public талбар, хайлт, шүүлт, эрэмбэ [каталогийн баримтад](vehicle-catalog.md) батлагдсан. Текст хайлтын тохирол, хуудаслалт зэрэг үлдсэн нарийвчлалыг тэр баримтад хөтөлнө.
- DB лавлахын бодит өгөгдлийн бүрэн жагсаалт болон admin үйлдэл бүрийн permission matrix. Идэвхгүй лавлахын өмнөх сонголтыг хадгалж засах/дахин нийтлэх дүрэм [лавлахын баримтад](../db/vehicle-reference-data.md) батлагдсан; нийтлэх бусад шаардлага хэвээр.
- Зургийн файл/пикселийн техникийн хязгаар болон зураг бүрийн гарчиг/тайлбарын public харагдах байдал. Зургийн тоо, формат, эх файл хадгалах, гарчиг/тайлбарын урт болон браузерын дэмжлэг шалгахгүй байх шаардлага батлагдсан.
- Тоноглолын seed жагсаалт; rich text editor-ийн сан, боломжууд, HTML аюулгүй харуулах арга болон дэлгэрэнгүй агуулгын тусдаа хязгаар. Хадгалалт HTML `text` гэж батлагдсан.

## Хүлээн авах шалгалт

1. Зөвхөн утгатай үндсэн гарчигтай бүртгэлийг ноорог хадгалж болно; энэ нь нийтэд харагдахгүй.
2. Нийтлэхэд дутуу заавал талбар бүрийг нэрлэж, нийтлэхийг зогсооно.
3. Цэвэр цахилгаан машинаас хөдөлгүүрийн багтаамж шаардахгүй; хуучин машинаас явсан км шаардана.
4. Үнэ харуулах горимд үнэ ба валют дутуу бол нийтлэхгүй. Үнэ асуух горимд хоёул хоосон байж болно; үнэ байгаа бол валют шаардлагатай.
5. `item_*` хоосон байж болно; бусад нийтлэх шаардлага хангагдсан бол нийтэлнэ. Render дээр харгалзах `title`, `description`, `main_image_id`-г ашиглаж, item утга бөглөсөн үед түүнийг харуулна.
6. Сонголттой талбар хоосон байгаагаас нийтлэхийг зогсоохгүй; бөглөсөн утгын формат, утгын шалгалт тусдаа үйлчилнэ.
7. Нийтлэгдсэн машины нөхцөл өөрчлөгдөхөд шаардлагыг дахин шалгана. Жишээ нь шинэ машиныг хуучин болговол явсан км шаардлагатай болно.
8. `draft`, `hidden`, `archived` машины мэдээлэл нийтэд жагсаалт болон шууд холбоосоор харагдахгүй.
9. Архивласан машиныг сэргээхэд `hidden` болно; шалгалт давж нийтлэх хүртэл нийтэд харагдахгүй.
10. `published` машиныг `sold` болгоход нийтлэлийн төлөв хэвээр үлдэж, үндсэн жагсаалтаас хасагдана. Өмнөх дэлгэрэнгүй холбоос "Зарагдсан" тэмдэглэгээтэй ажиллана; `hidden` болговол нийтэд харагдахгүй.
11. `sold -> available` буцаалт нийтлэлийн төлөвийг өөрчлөхгүй; нуусан машин автоматаар нийтлэгдэхгүй.
12. Нийтлэгдсэн машиныг байршилгүйгээр `in_stock` болгож хадгалахыг зөвшөөрөхгүй; салбар дангаараа хангалтгүй.
13. Анх бүртгэхдээ бодит ирэлтийн төлөвийг шууд сонгож, буруу төлөвийг буцааж засаж болно; нийтлэх болон нийтлэгдсэн мэдээлэл засах шалгалт хэвээр үйлчилнэ.
14. VIN/арлын дугаар хоосон эсвэл өөр машины бүртгэлтэй давхардсан байж болно. Энэ талбарт тусгай формат, урт, тэмдэгт, checksum болон давхардлын шалгалт хэрэглэхгүй; эдгээр шалтгаанаар хадгалах, нийтлэхийг зогсоохгүй.
15. Тоон талбар бүрийн доод, дээд хязгаарын утгыг зөвшөөрнө; хязгаараас гарсан болон бутархай утгыг ноорог хадгалах, нийтлэх үед зөвшөөрөхгүй. Автоматаар бүхэл болгохгүй.
16. `1900` болон тухайн оныг зөвшөөрнө; ирээдүйн оныг зөвшөөрөхгүй. Хоёр он бөглөгдсөн үед үйлдвэрлэсэн оноос өмнөх импортын оныг зөвшөөрөхгүй; ижил он байж болно.
17. Гүйлт `0` байж болно; үнэ, суудлын тоо болон хамаарах машины хөдөлгүүрийн багтаамж `0` байж болохгүй. Цэвэр цахилгаан машины хөдөлгүүрийн багтаамж хоосон байна.
18. Үнэ асуух горимд оруулсан үнэ мөн эерэг бүхэл тоо, батлагдсан хязгаартай байна; нийтэд үнийн дүн харуулахгүй. Үнэ харуулах горимд үнийг бүлэглэсэн форматаар харуулна.
19. Зургийн тоонд бүтээгдэхүүний түвшний дээд хязгаар тавихгүй; өмнөх 30 зургийн санал үйлчлэхгүй. Нэмэлт зураггүй байж болно; нийтлэхэд үндсэн зураг заавал, `item_image_id` сонголттой.
20. Зураг тус бүрийн гарчиг, тайлбарыг бие даан оруулах, засах, хоосон үлдээх боломжтой байна; эдгээрийг бөглөөгүйгээс нийтлэхийг зогсоохгүй.
21. Upload хийсэн эх файлыг өөрчлөлтгүй хадгална. Зургийн форматыг зөвхөн JPEG/PNG/WebP жагсаалтад байхгүй гэсэн шалтгаанаар хориглохгүй. Браузер харуулж чадахгүй зургийг upload хийх, хадгалах, үндсэн зураг эсвэл `item_image` болгон сонгож нийтлэхэд браузерын дэмжлэгийн шалгалт хийхгүй; тусгай preview шаардахгүй.
22. Гарчиг/`title` 255 тэмдэгт байж болно, 256 бол хадгалахгүй. Товч `desc`/тайлбар 512 тэмдэгт байж болно, 513 бол хадгалахгүй; ноорогт мөн шалгана, автоматаар таслахгүй.
23. Дэлгэрэнгүй тайлбарыг rich text editor-оор засна; товч `desc`-ийн 512 тэмдэгтийн шалгалтыг түүнд хэрэглэхгүй. Хоосон дэлгэрэнгүй тайлбар нийтлэхийг зогсоохгүй.
24. Өмнө сонгосон лавлах идэвхгүй болсон ч машины бусад мэдээллийг засаж, шаардлага хангасан ноорог/нуусан машиныг нийтэлж болно; лавлахыг заавал солихыг шаардахгүй. Шинэ сонголтоор идэвхгүй утга оноохыг зөвшөөрөхгүй.
25. Марк эсвэл загвар солиход тохирохгүй доод сонголтууд цэвэрлэгдэнэ. Нийтлэх үед хамаарал болон заавал талбарын шаардлага хангагдсан байна.
26. Public сайт өмнөх идэвхгүй лавлахын нэрийг хэвийн харуулна; "идэвхгүй" тэмдэглэгээ зөвхөн admin-д байна. Лавлах идэвхгүй болсноор машины нийтлэлийн төлөв автоматаар өөрчлөгдөхгүй.

Дараагийн шаардлага, загвар болон хэрэгжүүлэлт дээр дээрх талбаруудыг орхигдуулахгүй. Хамаарахгүй мэдээллийг зохиомол утгаар бөглөхийг шаардахгүй; нарийвчилсан дүрмийг тусад нь батална.
