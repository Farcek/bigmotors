## Нийтлэг урсгал

- Жагсаалт, нэмэх/засах modal, устгах confirmation нь colors-ийн бүтэцтэй ижил. Mantine `useForm`, Tabler icon, нэг цагаан body box ашиглана.
- Нэр заавал, trim хийсний дараа 1–255 тэмдэгт. Тайлбар сонголттой, 512 тэмдэгт; хоосон бол `null`.
- Дараалал signed int32, анхны утга 0. Идэвхтэй switch-ийн анхны утга true.
- Validation болон payload parse нь тухайн DTI schema-г ашиглана. ID, огноог сервер хариуцна.
- Идэвхтэй/идэвхгүй шүүлт болон page URL-д хадгалагдана. Хуудас 20 мөр, дараах хуудас байгаа эсэхэд 21 мөр уншина; нийт тоо зохиож харуулахгүй.
- Parent-тай лавлах харьяаллаар шүүнэ. Ангилал `rootOnly=true` шүүлттэй; `parentId` болон `rootOnly` хамт илгээгдэхгүй.
- API-ийн одоогийн дарааллыг ашиглана. API-д байхгүй нэрээр хайх/эрэмбэлэх боломж нэмээгүй.
- Mutation амжилттай бол жагсаалтыг дахин уншина. Нэмэлт cache, автомат retry, optimistic update байхгүй.
- Loading, empty, error/retry, success, pending болон давхар submit хамгаалалттай. Алдаа гарвал form утга хадгалагдана.

## Харьяалах лавлах

- Нэмэх үед идэвхтэй харьяалах лавлах сонгоно. Хувилбарын загвар болон түүний марк хоёул идэвхтэй байх шаардлагыг хадгална.
- Ангиллын бүх дээд шат идэвхтэй байх ёстой. Сонголтын нэрэнд шатлалыг харуулна. Идэвхгүй, олдохгүй эсвэл мөчлөгтэй дээд шаттай сонголтыг шинээр ашиглахгүй.
- Сонголтуудыг 100 мөрөөр дараалан бүрэн уншина; эхний 100 дээр таслахгүй. Нэмэх form нээхэд дахин уншина. Сонголт ачаалж байх эсвэл алдаатай үед шинээр хадгалахгүй, дахин унших боломжтой.
- Засах үед `brandId`, `modelId`, `parentId` нь readonly бөгөөд PATCH body-д огт орохгүй. Идэвхгүй болсон өмнөх харьяалалтай бүртгэлийн бусад талбарыг засаж болно.
- Жагсаалтын шүүлтэд идэвхгүй харьяалах лавлахыг мөн сонгож болно. Сонгосон ID олдохгүй бол ID-г fallback болгон харуулж, шүүлтийг цэвэрлэх боломжтой.
- Duplicate нэр, parent missing/inactive болон in-use алдааг хэрэглэгчид ойлгомжтой харуулна. Сервер эцсийн шалгалтыг хариуцна.

## Код ба зааг

`sysop/app/src/pages/references/` нь эдгээр 11 лавлахын нийтлэг form/page, UI-to-contract adapter, сонголтын ачаалал болон route-уудыг эзэмшинэ. `definitions.ts` нь лавлах бүрийн DTI namespace-г шууд ашиглана; динамик API URL зохиохгүй. Colors-ийн хэрэгжсэн тусдаа component-уудыг өөрчлөөгүй.

API, DB schema, service, migration болон Userly/ACL түр bypass-ийг өөрчлөөгүй. Production эрхийн хамгаалалт дууссан гэсэн үг биш. Бүтээгдэхүүний CRUD энэ ажилд ороогүй.
