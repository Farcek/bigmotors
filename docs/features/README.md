# Боломжууд ба төслийн хүрээ

Сайт ямар боломжтой байх, эхний хувилбарт юу багтах болон хүрээнээс гадуурх ажлыг энд тодорхойлно.

## Эхний хувилбарын суурь хүрээ

- Компанийн танилцуулга болон нүүр хуудас
- Автомашины каталог
- Марк, үнэ, он, төлөвөөр шүүх
- Автомашины зураг, үнэ, төлөв, техникийн үзүүлэлт бүхий дэлгэрэнгүй хуудас
- Онцлох болон шинээр нэмэгдсэн автомашинууд
- Үйлчилгээний танилцуулга
- Холбоо барих мэдээлэл

## Нэмэлтээр батлагдсан хүрээ

2026-09-08-ны хэрэглэгчийн шаардлагаар дараах хүрээг нэмсэн.

- Public website нь [PWA боломжтой](pwa.md) байна. Нарийвчилсан боломж, хүлээн авах шалгуур тодорхойлох шаардлагатай.
- Admin backend (`sysop-server`), admin frontend (`sysop-app`) нь төслийн бүтцэд багтана. Удирдах мэдээлэл, үйлдэл, хэрэглэгчийн эрхийн нарийвчилсан хүрээ хараахан тогтоогүй.
- `sysop-dti` нь `sysop-server` болон `sysop-app` хооронд мэдээлэл дамжуулах бүтэц (API contract)-ийг хариуцна. Website/admin-ийн дундын enum, тогтмол утга, helper, functions-ийг `core`-д байрлуулна. Үүргийн заагийг [monorepo ADR](../adr/0001-use-monorepo.md)-д хөтөлнө.

## Тусад нь шийдэх хүрээ

Дараах боломжууд одоогоор батлагдсан хүрээнд ороогүй. Нэмэх бол шаардлага, ажлын хэмжээ болон хүлээн авах шалгуурыг тусад нь тодорхойлно.

- Admin хэсгийн удирдах мэдээлэл, үйлдлүүд, хэрэглэгчийн эрх болон эхний хувилбарт багтах хэмжээ
- Онлайн захиалга, төлбөр, зээлийн хүсэлт
- Хэрэглэгчийн бүртгэл, хадгалсан автомашин, харьцуулалт
- CRM болон бусад системтэй холболт
- Олон хэлний дэмжлэг

## Боломжийн баримтын бүтэц

Боломж бүрийг тусдаа Markdown файлд дараах бүтэцтэй бичнэ.

- Нэр, зорилго, ашиглах хэрэглэгч
- Хэрэглэгчийн урсгал болон үйлдлүүд
- Багтах ажил, багтахгүй ажил
- Өгөгдөл, шалгалтын дүрэм, онцгой болон алдааны төлөв
- Хүлээн авах шалгуур
- Хамаарал, ач холбогдол, төлөв, нээлттэй асуулт

Хүрээний өөрчлөлтийг шалтгаан, огноотой тэмдэглэж, холбогдох [UI / UX](../ui/README.md), [өгөгдлийн сан](../db/README.md), [ADR](../adr/README.md)-тай холбоно.
