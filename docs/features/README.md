# Боломжууд ба төслийн хүрээ

Сайт ямар боломжтой байх, эхний хувилбарт юу багтах болон хүрээнээс гадуурх ажлыг энд тодорхойлно.

## Батлагдсан үндсэн зааг

2026-09-09: Сайт нь **автомашин, сэлбэг хэрэгсэл, дугуй гэсэн үндсэн гурван төрлийн бүтээгдэхүүний каталог болон компанийн танилцуулга** байна. **Сайтаар бүтээгдэхүүн худалдахгүй.** Сагс, checkout, онлайн худалдааны захиалга болон төлбөр хүрээнээс гадуур. Дэлгэрэнгүй зааг, батлагдаагүй боломж болон суурь шалгуурыг [бүтээгдэхүүний хүрээ](scope.md)-д хөтөлнө.

## Каталог ба агуулгын нарийвчлах санал

- [Автомашины талбарууд ба бөглөх шаардлага](vehicle-fields.md): 33 талбар болон `item_*` талбаруудын ноорог/нийтлэх нөхцөл, default, fallback дүрэм; 2026-09-09-нд батлагдсан.
- [Сэлбэг хэрэгслийн талбарууд](part-fields.md): 2026-09-10-нд боловсруулсан 25 талбарын санал, давтагдах нийцлийн мэдээлэл; хараахан батлагдаагүй.
- [Дугуйн талбарууд](tire-fields.md): 2026-09-10-нд боловсруулсан 33 талбарын санал; хэмжээ, индекс болон ширхэг/нийлүүлэлтийн мэдээллийн зааг; хараахан батлагдаагүй.

**Одоогийн төвлөрөл:** автомашин, сэлбэг хэрэгсэл, дугуйн каталог болон бүтээгдэхүүний мэдээллийн admin удирдлага. **CRM-ийг тусдаа системээр боловсруулна; энэ төсөлд орохгүй.** CRM холболт мөн одоогоор батлагдаагүй. Өмнөх DOCX баримтын CRM шаардлагыг шууд хэрэгжүүлэхгүй.

Доорх нь өмнө бүртгэсэн анхны жагсаалт. Каталог болон компанийн танилцуулгын үндсэн чиглэл батлагдсан. [Нэгж автомашины 33 талбар](vehicle-fields.md) болон бөглөх шаардлага батлагдсан; нийтэд харуулах талбарын бүрэн жагсаалт, шүүлтэд ашиглах дүрмийг дараа тогтооно. Сэлбэг, дугуйн тусгай талбар, тусдаа хуудас болон нэмэлт хэсгүүдийн нарийвчилсан хүрээ нээлттэй.

- Компанийн танилцуулга болон нүүр хуудас
- Автомашины каталог
- Сэлбэг хэрэгслийн каталог; дэд ангилал, талбар болон шүүлтийг нарийвчлах
- Дугуйн каталог; талбар болон шүүлтийг нарийвчлах
- Марк, үнэ, он, төлөвөөр шүүх
- Автомашины зураг, үнэ, төлөв, техникийн үзүүлэлт бүхий дэлгэрэнгүй хуудас
- Онцлох болон шинээр нэмэгдсэн автомашинууд
- Үйлчилгээний танилцуулга
- Холбоо барих мэдээлэл

## Нэмэлтээр батлагдсан хүрээ

2026-09-09: Бүх төрлийн product-ийн жагсаалтын item-д зориулсан `item_title`, `item_desc`, `item_image` нэмэлт талбаруудыг бүртгэсэн. Зориулалт болон дараа шийдэх дүрмийг [DB баримтын тэмдэглэл](../db/README.md#product-ийн-жагсаалтын-нэмэлт-талбарууд)-д хадгалсан. Энэ нь автомашины 33 талбарын жагсаалтыг орлохгүй, нийтлэг product түвшний нэмэлт шаардлага юм.

2026-09-08-ны хэрэглэгчийн шаардлагаар дараах хүрээг нэмсэн.

- Public website нь [PWA боломжтой](pwa.md) байна. Нарийвчилсан боломж, хүлээн авах шалгуур тодорхойлох шаардлагатай.
- Admin backend (`sysop-server`), admin frontend (`sysop-app`) нь төслийн бүтцэд багтана. Удирдах мэдээлэл, үйлдэл, хэрэглэгчийн эрхийн нарийвчилсан хүрээ хараахан тогтоогүй.
- `sysop-dti` нь `sysop-server` болон `sysop-app` хооронд мэдээлэл дамжуулах бүтэц (API contract)-ийг хариуцна. Website/admin-ийн дундын enum, тогтмол утга, helper, functions-ийг `core`-д байрлуулна. Үүргийн заагийг [monorepo ADR](../adr/0001-use-monorepo.md)-д хөтөлнө.

## Тусад нь шийдэх хүрээ

2026-09-09-өөс боломж болон үндсэн заагийг энэ хавтаст хэлэлцэж эхэлсэн. [Tech spec task-ууд](../../docs.task.md) нь зөвхөн техникийн шийдвэрийн бүртгэл хэвээр. [Дараа хэлэлцэх бүртгэл](../deferred-decisions.md)-ийн саналуудаас баталсныг холбогдох feature баримтад тусгана; тэдгээрийг техникийн сонголтын батлах шалгуур болгохгүй.

Дараах боломжууд одоогоор батлагдсан хүрээнд ороогүй. Нэмэх бол шаардлага, ажлын хэмжээ болон хүлээн авах шалгуурыг тусад нь тодорхойлно.

- Admin хэсгийн удирдах мэдээлэл, үйлдлүүд, хэрэглэгчийн эрх болон эхний хувилбарт багтах хэмжээ
- Лавлах хүсэлт, төлбөргүй reservation, зээлийн хүсэлт (онлайн худалдааны захиалга болон төлбөр нь дээр зааснаар хүрээнээс гадуур)
- Хэрэглэгчийн бүртгэл, хадгалсан автомашин, харьцуулалт
- Тусдаа CRM болон бусад системтэй холболт (CRM системийг өөрийг нь энэ төсөлд хөгжүүлэхгүй)
- Олон хэлний дэмжлэг

## Боломжийн баримтын бүтэц

Боломж бүрийг тусдаа Markdown файлд дараах бүтэцтэй бичнэ.

- Нэр, зорилго, ашиглах хэрэглэгч
- Хэрэглэгчийн урсгал болон үйлдлүүд
- Багтах ажил, багтахгүй ажил
- Өгөгдөл, шалгалтын дүрэм, онцгой болон алдааны төлөв
- Хүлээн авах шалгуур
- Хамаарал, ач холбогдол, төлөв, нээлттэй асуулт

Хүрээний өөрчлөлтийг шалтгаан, огноотой тэмдэглэж, холбогдох [UI / UX](../ui/README.md), [өгөгдлийн сан](../db/README.md), [ADR](../adr/README.md)-тай холбоно.
