# Боломжууд ба төслийн хүрээ

Сайт ямар боломжтой байх, эхний хувилбарт юу багтах болон хүрээнээс гадуурх ажлыг энд тодорхойлно.

## Батлагдсан үндсэн зааг

2026-09-09: Сайт нь **автомашин, сэлбэг хэрэгсэл, дугуй гэсэн үндсэн гурван төрлийн бүтээгдэхүүний каталог болон компанийн танилцуулга** байна. **Сайтаар бүтээгдэхүүн худалдахгүй.** Сагс, checkout, онлайн худалдааны захиалга болон төлбөр хүрээнээс гадуур. Дэлгэрэнгүй зааг, батлагдаагүй боломж болон суурь шалгуурыг [бүтээгдэхүүний хүрээ](scope.md)-д хөтөлнө.

## Каталог ба агуулгын нарийвчлах санал

- [Admin UI demo](admin-ui-demo.md): `/demo`, `/demo/list`, `/demo/form` тусгаарласан жишээ; бодит API/DB-д хүрэхгүй.
- [Admin өнгөний CRUD](admin-colors.md): `/references/colors`, бодит DTI API-д холбогдсон жагсаалт, нэмэх/засах form болон устгах баталгаажуулалт.

- [Бүтээгдэхүүний нийтлэг дүрэм](product-common-rules.md): автомашин, сэлбэг, дугуйн текст, зураг, үнэ, нийтлэх, лавлах болон каталогийн нийтлэг зарчим; 2026-09-10-нд ижил хэрэглэхээр батлагдсан.
- [Admin нэвтрэлт, хэрэглэгч ба ACL](admin-authentication-access.md): Chip CRM-тэй ижил Userly login, user management, local profile болон ACL аргачлал; 2026-09-10-нд батлагдсан. Каталогийн permission/scope matrix нээлттэй.
- [Автомашины public каталог](vehicle-catalog.md): карт, дэлгэрэнгүйд харуулах талбар, хайлт, шүүлт, эрэмбэ болон UI лавлагааны зааг; 2026-09-10-нд батлагдсан.
- [Автомашины талбарууд ба бөглөх шаардлага](vehicle-fields.md): 33 талбар болон `item_*` талбаруудын ноорог/нийтлэх нөхцөл, default, fallback дүрэм 2026-09-09-нд; төлөв шилжилт, зарагдсан машины харагдах байдал, арлын дугаар болон тоон талбарын дүрэм 2026-09-10-нд батлагдсан.
- [Автомашины лавлах ба enum/const](../db/vehicle-reference-data.md): 7 DB лавлах, лавлах хөтлөх дүрэм болон 10 тогтмол бүлгийн утга, утгын код; 2026-09-10-нд батлагдсан.
- [Сэлбэг хэрэгслийн талбарууд](part-fields.md): лавлах/enum ангилал болон автомашинтай ижил нийтлэг дүрэм батлагдсан; 25 талбарын онцлог хэсэг, нэмэлт бөглөх шаардлага нээлттэй.
- [Сэлбэгийн лавлах ба enum/const](../db/part-reference-data.md): 5 үндсэн лавлах (2 шинэ + 3 дундын), 7 тогтмол бүлэг; 2026-09-10-нд батлагдсан. Нэмэлт 3 лавлахыг дараа шийднэ.
- [Дугуйн талбарууд](tire-fields.md): лавлах/enum ангилал болон автомашинтай ижил нийтлэг дүрэм батлагдсан; 33 талбарын онцлог хэсэг, нэмэлт бөглөх шаардлага нээлттэй.
- [Дугуйн лавлах ба enum/const](../db/tire-reference-data.md): 3 лавлах (2 шинэ + 1 дундын), 11 тогтмол бүлэг; 2026-09-10-нд батлагдсан. Индекс болон нэмэлт тэмдэглэгээг дараа шийднэ.

**Одоогийн төвлөрөл:** автомашин, сэлбэг хэрэгсэл, дугуйн каталог болон бүтээгдэхүүний мэдээллийн admin удирдлага. **CRM-ийг тусдаа системээр боловсруулна; энэ төсөлд орохгүй.** CRM холболт мөн одоогоор батлагдаагүй. Өмнөх DOCX баримтын CRM шаардлагыг шууд хэрэгжүүлэхгүй.

Доорх нь өмнө бүртгэсэн анхны жагсаалт. Каталог болон компанийн танилцуулгын үндсэн чиглэл батлагдсан. [Нэгж автомашины 33 талбар](vehicle-fields.md), бөглөх шаардлага болон [public каталогийн талбар, хайлт, шүүлт, эрэмбэ](vehicle-catalog.md) батлагдсан; үлдсэн нарийвчлалыг холбогдох баримтад хөтөлнө. Сэлбэг, дугуйн тусгай талбар, тусдаа хуудас болон нэмэлт хэсгүүдийн нарийвчилсан хүрээ нээлттэй.

- Компанийн танилцуулга болон нүүр хуудас
- Автомашины каталог
- Сэлбэг хэрэгслийн каталог; дэд ангилал, талбар болон шүүлтийг нарийвчлах
- Дугуйн каталог; талбар болон шүүлтийг нарийвчлах
- Марк, үнэ, он, төлөвөөр шүүх
- Автомашины зураг, үнэ, төлөв, техникийн үзүүлэлт бүхий дэлгэрэнгүй хуудас
- Онцлох болон шинээр нэмэгдсэн автомашинууд
- Үйлчилгээний танилцуулга
- Холбоо барих мэдээлэл

## Нэмэлтээр батлагдсан хүрээ

2026-09-10: Бүх product-ийн `item_title`, `item_desc`, `item_image_id` сонголттой; render үед `title`, `description`, `main_image_id`-аас тус тус автоматаар авна. `description` нь товч тайлбар/SEO/share, `content` нь дэлгэрэнгүй хуудасны үндсэн rich text агуулга. Энэ нь өмнөх item requiredness/fallback дүрмийг орлоно. Үндсэн шаардлагыг [нийтлэг дүрэм](product-common-rules.md), schema-д тусгах тэмдэглэлийг [DB баримтад](../db/README.md#product-ийн-жагсаалтын-нэмэлт-талбарууд) хадгалсан.

2026-09-08-ны хэрэглэгчийн шаардлагаар дараах хүрээг нэмсэн.

- Public website нь [PWA боломжтой](pwa.md) байна. Нарийвчилсан боломж, хүлээн авах шалгуур тодорхойлох шаардлагатай.
- Admin backend (`sysop-server`), admin frontend (`sysop-app`) нь төслийн бүтцэд багтана. [Userly нэвтрэлт ба ACL аргачлал](admin-authentication-access.md) батлагдсан; каталогийн үйлдэл бүрийн permission/scope matrix болон үлдсэн admin дэлгэцийн хүрээ нээлттэй.
- `sysop-dti` нь `sysop-server` болон `sysop-app` хооронд мэдээлэл дамжуулах бүтэц (API contract)-ийг хариуцна. Website/admin-ийн дундын enum, тогтмол утга, helper, functions-ийг `core`-д байрлуулна. Үүргийн заагийг [monorepo ADR](../adr/0001-use-monorepo.md)-д хөтөлнө.

## Тусад нь шийдэх хүрээ

2026-09-09-өөс боломж болон үндсэн заагийг энэ хавтаст хэлэлцэж эхэлсэн. [Tech spec task-ууд](../../docs.task.md) нь зөвхөн техникийн шийдвэрийн бүртгэл хэвээр. [Дараа хэлэлцэх бүртгэл](../deferred-decisions.md)-ийн саналуудаас баталсныг холбогдох feature баримтад тусгана; тэдгээрийг техникийн сонголтын батлах шалгуур болгохгүй.

Дараах боломжууд одоогоор батлагдсан хүрээнд ороогүй. Нэмэх бол шаардлага, ажлын хэмжээ болон хүлээн авах шалгуурыг тусад нь тодорхойлно.

- Admin хэсгийн үлдсэн үйлдэл/дэлгэц, каталогийн permission/scope matrix. Account, invitation, role/permission management-ийг Userly хариуцах батлагдсан заагийг өөрчлөхгүй.
- Лавлах хүсэлт, төлбөргүй reservation, зээлийн хүсэлт (онлайн худалдааны захиалга болон төлбөр нь дээр зааснаар хүрээнээс гадуур)
- Хэрэглэгчийн бүртгэл, хадгалсан автомашин, харьцуулалт
- Тусдаа CRM болон бусад системтэй холболт (CRM системийг өөрийг нь энэ төсөлд хөгжүүлэхгүй)
- Олон хэлний дэмжлэг
