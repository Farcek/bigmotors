# Сэлбэгийн ангиллын tree view

- Төлөв: Хэрэгжүүлсэн, 2026-09-12.
- URL: `/references/part-categories` хэвээр.
- Холбоотой: [Лавлахын CRUD](admin-reference-crud.md), [Admin UI kit](../ui/admin-ui-kit.md).

## Байрлал ба сонголт

- Нэг цагаан ажлын хэсгийн зүүн талд ангиллын tree view, баруун талд CRUD жагсаалт байрлана.
- Mantine `sm` (одоогоор 768px)-ээс нарийн дэлгэцэд tree дээр, жагсаалт доор байрлана. Tree болон өргөн хүснэгт зөвхөн өөрийн хэсэг дотроо гүйнэ.
- Tree нь бүх ангиллыг бүх төлөвөөр харуулна. Мөчир бүрийг дэлгэх/хураах, бүгдийг дэлгэх/хураах болон шинэчлэх удирдлагатай.
- Ангиллын нэр сонгоход баруун талд зөвхөн шууд дэд ангиллууд нь харагдана. Мөчир дэлгэх сум дарахад сонголт солигдохгүй.
- “Бүх ангилал” нь өмнөх шүүлтгүй харагдац; “Үндсэн ангилал” нь `parentId = null` бүртгэлүүд. Анхны харагдац бүх ангилал байна.
- Сонголт `parentId`, үндсэн ангиллын шүүлт `rootOnly` query-д хадгалагдана; хоёул зэрэг идэвхжихгүй. Сонголт солиход page эхлэлд буцаж, төлөвийн шүүлтийг хадгална.
- Refresh болон Back/Forward үед сонгосон ангиллын дээд мөчрүүд автоматаар нээгдэнэ. Keyboard сумуудаар tree дотор шилжиж, Enter/Space-аар сонгоно.
- Tree-ийн төлөв нь санах ойд байна; browser storage болон нэмэлт cache ашиглахгүй.

## CRUD

- Сонгосон ангилал дор “Нэмэх” дарахад дээд ангилал урьдчилан бөглөгдөнө. Form дотор өөр зөвшөөрөгдсөн parent сонгох эсвэл үндсэн ангилал болгох боломж хэвээр. Reset нь form нээсэн үеийн харьяаллыг сэргээнэ.
- “Бүх ангилал” болон “Үндсэн ангилал” харагдацаас нэмэхэд харьяалал анх `null` байна. Tree сонголтын дараа шууд нэмэхэд өмнөх parent дамжихгүй.
- Засах үед `parentId` өөрчлөхгүй, PATCH body-д оруулахгүй. Drag-and-drop болон ангилал зөөх боломж нэмээгүй.
- Сонгосон ангиллын гарчгийн menu-ээс тухайн ангиллыг засах/устгах боломжтой. Дэд ангилалгүй үед ч үйлдлүүд ашиглагдана. Жагсаалтын мөрийн өмнөх үйлдлүүд хэвээр.
- Сонгосон ангиллыг устгавал түүний дээд ангилал руу, үндсэн ангилал устгавал үндсэн жагсаалт руу шилжинэ. Дэд ангилалтай/ашиглагдаж буй бүртгэлийг устгах backend хориг хэвээр.
- Идэвхгүй ангилал болон идэвхгүй дээд ангилалтай мөчрүүдийг үзэж/засаж болно; тэдгээрийн дор шинээр нэмэхгүй. Tree ачаалж байгаа, алдаатай эсвэл сонгосон parent олдоогүй үед нэмэхийг хориглоно.
- Create/update/delete амжилттай бол tree болон жагсаалтыг дахин уншина. Төлөвийн шүүлт нь зөвхөн баруун жагсаалтад үйлчилнэ.

## Хэрэгжүүлэлт

- Mantine `Tree`, `useTree`, `ScrollArea`, `Flex`, `Divider` болон бэлэн props ашиглана. Шинэ custom CSS class/media query нэмээгүй; Tree-ийн `elementProps` нь сангийн өөрийн style/event холбоосыг хадгална.
- Нийтлэг `ReferencePage`, `ReferenceForm`, `useParentOptions`-ийг ашиглана. Sidebar зөвхөн сэлбэгийн ангиллын route дээр идэвхтэй байна.
- Parent сонголтод өмнө нь ачаалдаг өгөгдлийг tree-д давхар ашиглана; tree-д зориулж ижил бүх жагсаалтыг дахин татахгүй. Бүх хуудсыг 100-аар дараалан уншина.
- Дутуу parent эсвэл циклтэй өгөгдлийг нуухгүй: анхааруулгатайгаар дээд түвшинд харуулна. Өгөгдлийг автоматаар засахгүй.
- API contract, backend, DB schema/migration, Userly/ACL болон бодит өгөгдөл өөрчлөгдөөгүй.
