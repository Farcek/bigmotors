# Сэлбэгийн лавлах ба тогтмол сонголтууд

- Огноо: 2026-09-10
- Төлөв: Үндсэн лавлах ба enum/const ангилал батлагдсан; нэмэлт лавлахууд шийдээгүй
- Үндэслэл: Хэрэглэгч сэлбэгийн 5 үндсэн лавлах, 7 enum/const бүлгийн саналыг баталсан
- Холбоотой баримт: [Сэлбэгийн талбарууд](../features/part-fields.md), [Автомашины лавлах](vehicle-reference-data.md), [ADR 0017](../adr/0017-use-part-reference-data.md)

## Үндсэн DB лавлах

Нийт **5 лавлах: 2 шинэ + 3 дундын**. Үндсэн/дэд ангилал нь хоёр тусдаа лавлах биш, нэг шаталсан ангилал байна.

| ID | Лавлах | Ашиглах талбар | Шинэ эсвэл дундын |
| --- | --- | --- | --- |
| PL01 | Сэлбэгийн ангилал | P02 Үндсэн ангилал, P03 Дэд ангилал | Шинэ; эцэг/дэд ангиллын хамааралтай |
| PL02 | Сэлбэгийн үйлдвэрлэгч / брэнд | P04 | Шинэ; тохирох автомашины маркаас тусдаа |
| PL03 | Автомашины марк | P10 Нийцлийн бичлэгийн марк | Автомашины маркын лавлахтай дундын |
| PL04 | Автомашины загвар | P10 Нийцлийн бичлэгийн загвар | Автомашины загварын лавлахтай дундын; маркын хамаарлыг хадгална |
| PL05 | Салбар / байршил | P19 | Автомашинд ашиглах салбарын лавлахтай дундын |

Дундын марк, загвар, салбарын хуулбар лавлах үүсгэхгүй. Нийцлийн марк/загвар нь каталогийн нэг бодит автомашин биш, лавлах өгөгдөлтэй холбогдоно. Нийцлийн бүх талбар, заавал бөглөх дүрэм болон олон салбарын нарийвчлалыг энэ шийдвэрээр батлаагүй.

## Enum/const бүлгүүд

2026-09-10-ны дараагийн [нэгтгэсэн schema баталгаагаар](catalog-schema-proposal.md#сэлбэгдугуйн-тогтмол-утгууд) condition, mounting_position, price_unit, availability-ийн утгууд болон text + CHECK хадгалалт батлагдсан. Доорх өмнөх тэмдэглэлийн эдгээр утгыг нээлттэй гэсэн төлөвийг орлоно; нэмэлт лавлах/seed/permission matrix хэвээр нээлттэй.

| ID | Бүлэг | Ашиглах талбар |
| --- | --- | --- |
| PE01 | Нөхцөл | P06 |
| PE02 | Суурилуулах байрлал | P11 |
| PE03 | Валют | P14 |
| PE04 | Үнэ харуулах хэлбэр | P15 |
| PE05 | Үнийн нэгж | P16 |
| PE06 | Бэлэн байдлын төлөв | P18 |
| PE07 | Нийтлэлийн төлөв | P23 |

Эдгээр **7 бүлгийг** admin-аас дурын утга нэмдэг DB лавлах биш, кодын enum/const байдлаар хөтөлнө. Website/admin-д дундын тогтмолыг `packages/core` хариуцах батлагдсан үүрэг хэвээр. Онцлох эсэх нь boolean тул энэ тоонд ороогүй.

2026-09-10: [Нийтлэг бүтээгдэхүүний дүрмээр](../features/product-common-rules.md) PE03 валют (`MNT`), PE04 үнэ харуулах хэлбэр (`show_price`, `inquire`), PE07 нийтлэлийн төлөв (`draft`, `published`, `hidden`, `archived`) нь автомашин/дугуйтай дундын утга, дүрэмтэй болсон. Бусад бүлгийн бүрэн утга, TypeScript identifier/хэлбэр болон DB хадгалалтын арга нээлттэй.

## Лавлахын нийтлэг дүрэм

Admin нэмэх/нэр засах/идэвхгүй болгох, ашиглагдаж байгаа лавлахыг шууд устгахгүй байх болон [идэвхгүй лавлахын өмнөх сонголтыг хадгалах дүрэм](../features/product-common-rules.md) сэлбэгийн бүх үндсэн лавлахад үйлчилнэ. Өмнөх сонголттой бүтээгдэхүүнийг засах/нийтлэхэд заавал солихгүй; шинэ сонголт зөвхөн идэвхтэй байна. Үндсэн/дэд ангилал болон нийцлийн марк/загварын хамаарал хэвээр шалгагдана. Public нэр хэвийн, идэвхгүй тэмдэглэгээ зөвхөн admin-д байна.

## Нэмэлт лавлахууд

Дараах **3 лавлах үндсэн 5-ын тоонд ороогүй**, хэрэгцээгээр шийдэхээр үлдсэн:

| Сэдэв | Одоогийн зааг |
| --- | --- |
| Сэлбэгийн загвар / цуврал (P05) | Эхний ээлжид текст байж болно; давтагдах цувралын хэрэгцээгээр лавлах болгох эсэхийг шийднэ |
| Автомашины үе / кузовын код (P10) | Нийцлийг нарийвчлах шаардлагатай үед лавлах болгох эсэхийг шийднэ |
| Хөдөлгүүрийн код (P10) | Хөдөлгүүрээр ялгаж нийцэл тогтоох хэрэгцээгээр лавлах болгох эсэхийг шийднэ |

Үе/кузовын код нь кузовын төрөл эсвэл комплектаци гэсэн үг биш. Эдгээр нэмэлт лавлахын хүснэгт, seed болон удирдах UI-г батлагдсан гэж үзэхгүй.

## Код ба дугаарын зааг

P07 дотоод SKU, P08 үйлдвэрлэгчийн part number, P09 OEM лавлах дугааруудыг эхний хувилбарт сонгодог DB лавлах биш, бүтээгдэхүүний код/дугаар хэлбэрээр бүртгэнэ. Гурвыг нэг утгад нэгтгэхгүй. OEM лавлах дугаар гэдэг нэр нь энэ бүртгэлийн DB лавлах гэсэн ангилалтай ижил биш.

## Дараа шийдэх зүйлс

- Хүснэгт/нийтлэг багана/холбоос/нэрийн давхардлын дүрэм [батлагдсан](reference-tables.md). Бодит лавлахын өгөгдөл, seed, normalization болон constraint/index-ийн хэрэгжүүлэлт нээлттэй.
- Сэлбэгийн нийт 25 талбарын үлдсэн онцлог санал, нийтлэг дүрмээс гаднах нийтлэх/public/filter шаардлага.
- PE01 нөхцөл, PE02 байрлал, PE05 үнийн нэгж, PE06 бэлэн байдлын утга/дүрэм. PE03/PE04/PE07 нийтлэг дүрмээр батлагдсан.
- Нэмэлт 3 лавлахын хэрэгцээ, нийцлийн нарийвчлал, олон салбарын мэдээлэл.
- Лавлах удирдах үйлдэл бүрийн permission matrix; устгахгүй/идэвхгүй болгох ба хуучин сонголт хадгалах зарчим нийтлэг дүрмээр батлагдсан.

## Баталгаажуулалтын зааг

2026-09-10-ны лавлах schema баталгаагаар `part_categories`, `part_brands` болон дундын хүснэгтүүдийн нэр, нийтлэг багана/төрөл, холбоос, нэрийн давхардлын дүрмийг [лавлахын schema баримтад](reference-tables.md) баталсан. Доорх өмнөх ангиллын баталгааг өргөжүүлсэн; код, migration үүсгээгүй.

Энэ шийдвэр нь лавлахын ангилал, 3 дундын лавлах ашиглах болон код/дугаарын заагт хамаарна. Сэлбэгийн 25 талбарын бүх санал, дугуйн лавлах, enum-ийн бүх утга, DB schema, migration, seed эсвэл кодын хэрэгжүүлэлтийг баталсан гэсэн үг биш. Tech spec task-уудын төлөв өөрчлөгдөөгүй.

2026-09-10-ны дараагийн баталгаагаар автомашинтай ижил нийтлэг дүрэм сэлбэгт үйлчилнэ. Үүнд дээрх 3 enum бүлгийн утга болон лавлахын lifecycle орсон; онцлог бүлгүүд нээлттэй хэвээр.
