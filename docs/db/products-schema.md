# Products-ийн логик бүтэц

- Огноо: 2026-09-10
- Төлөв: Бүтэц баталсан; Drizzle schema болон trigger source болон migration үүссэн; бодит DB-д ажиллуулаагүй. [Хэрэгжүүлэлтийн зааг](../operations/db-schema.md).
- Үндэслэл: Хэрэглэгч `products`-ийн талбарын бүтэц, зориулалт, бөглөх дүрмийг эхлээд баталж, зураг болон `content` хадгалалтыг дараа шийдэх саналыг зөвшөөрсөн.
- Холбоотой баримт: [DB тойм](README.md), [Бүтээгдэхүүний нийтлэг дүрэм](../features/product-common-rules.md)

## Хамрах хүрээ

`products` нь автомашин, сэлбэг хэрэгсэл, дугуйн нийтлэг мэдээллийг эзэмшинэ. Төрөлд онцлог марк, загвар, хэмжээ, нөхцөл, борлуулалтын болон бэлэн байдлын мэдээллийг энд нэгтгэхгүй.

Доорх 18 талбарын нэр, зориулалт, бөглөх нөхцөлийг баталсан. Энэ нь бүх database, `vehicles`/`parts`/`tires`, лавлах, media хүснэгтүүдийн нарийвчилсан schema эсвэл migration-ийг баталсан гэсэн үг биш.

## Баталсан талбарууд

| Талбар | Зориулалт | Бөглөх нөхцөл / default |
| --- | --- | --- |
| `id` | Бүтээгдэхүүний үндсэн танигч | Заавал; UUID v4, DB default gen_random_uuid() |
| `product_type` | Бүтээгдэхүүний төрөл | Заавал; `vehicle`, `part`, `tire` |
| `title` | Үндсэн гарчиг | Ноорог/нийтлэхэд заавал; 255 тэмдэгт хүртэл |
| `description` | Энгийн текст short description, SEO, share | Ноорог/нийтлэхэд сонголттой; 512 тэмдэгт хүртэл |
| `content` | Дэлгэрэнгүй танилцуулгын хуудасны үндсэн HTML агуулга | `text`, nullable; 512 тэмдэгтийн хязгаар хамаарахгүй |
| `main_image_id` | Үндсэн зургийн холбоос | Ноорогт сонголттой, нийтлэхэд upload дууссан зураг заавал |
| `item_title` | Жагсаалтын гарчгийг тусад нь тохируулах | Сонголттой; 255 тэмдэгт хүртэл |
| `item_desc` | Жагсаалтын товч тайлбарыг тусад нь тохируулах | Сонголттой; 512 тэмдэгт хүртэл |
| `item_image_id` | Жагсаалтын зургийг тусад нь тохируулах | Сонголттой; сонгосон зураг upload дууссан байна |
| `price` | Бүтээгдэхүүний үнэ | Сонголттой/нөхцөлтэй; бүхэл төгрөг, `1–99,999,999,999`; `show_price` үед нийтлэхэд заавал |
| `currency` | Үнийн валют | Зөвхөн `MNT`; үнэ оруулсан бол нийтлэхэд заавал |
| `price_display_mode` | Үнэ харуулах арга | Ноорогт сонголттой, нийтлэхэд заавал; `show_price`, `inquire`; default байхгүй |
| `publication_status` | Нийтлэлийн төлөв | Заавал; `draft`, `published`, `hidden`, `archived`; default `draft` |
| `is_featured` | Онцлох тэмдэглэгээ | Заавал; default `false` |
| `internal_note` | Дотоод тэмдэглэл | Сонголттой; зөвхөн admin-д |
| `first_published_at` | Анх нийтэлсэн огноо | Анх нийтлэх хүртэл хоосон; анх нийтлэхэд онооно, дахин нийтлэхэд өөрчлөхгүй |
| `created_at` | Үүсгэсэн огноо | Заавал, систем онооно |
| `updated_at` | Сүүлд зассан огноо | Заавал, систем хөтөлнө |

## Render fallback

| Бөглөөгүй талбар | Render дээр авах утга |
| --- | --- |
| `item_title` | `title` |
| `item_desc` | `description` |
| `item_image_id` | `main_image_id` |

Талбар бүрийн fallback бие даасан; бөглөсөн item утга давуу эрхтэй. Орлуулсан утгыг DB-д хуулж хадгалахгүй. Үндсэн утга өөрчлөгдвөл хоосон item талбарын render дагаж шинэчлэгдэнэ.

`item_desc`, `description` хоёул хоосон бол тайлбар харуулахгүй. `content`-оос автоматаар товч тайлбар үүсгэхгүй. Зургийн fallback нь холбоос бөглөөгүй үед үйлчилнэ; браузер файлыг харуулж чадах эсэхээр зураг солих дүрэм биш.

## Нийтлэх ба хадгалах зааг

Ноорогт хэрэглэгчээс зөвхөн үндсэн гарчиг шаардана; систем төрөл, танигч, default болон огноогоо хөтөлнө. Нийтлэхэд заавал талбарыг бүх мөрөнд `NOT NULL` болгохгүй, ноорог дутуу мэдээлэлтэй байж болно.

`inquire` горимд дотоод үнэ байсан ч нийтэд харуулахгүй. Нийтлэлийн шилжилт, идэвхгүй лавлах, зураг болон нийтэд харагдах дүрмийн үндсэн эх сурвалж нь [нийтлэг дүрэм](../features/product-common-rules.md). Төрөл тус бүрийн нийтлэх шаардлага мөн үйлчилнэ.

## Физик schema-ийн баталгаа

- `content` хадгалалт 2026-09-10-нд HTML `text`, nullable гэж батлагдсан. Editor болон аюулгүй HTML render/sanitization хэрэгсэл нээлттэй; editor JSON хадгалахгүй.
- Зургийн хадгалалт батлагдсан: эх файл hard disk дээр, бүртгэл `product_images` хүснэгтэд. `main_image_id`, `item_image_id` нь `product_images.id` рүү заана. [Багана, эзэмшил/дараалал/устгах дүрэм](product-images.md) нэгтгэсэн schema-тай хамт батлагдсан.
- ID: UUID v4, DB default `gen_random_uuid()` гэж баталсан.
- Физик төрлийн шийдвэр: гарчиг `varchar(255)`, товч тайлбар `varchar(512)`, үнэ `bigint`, тэмдэглэл `text`, огноо `timestamptz`. Тогтмол сонголт `text + CHECK`; timestamp default/update trigger-ийн арга нэгтгэсэн schema-д батлагдсан.
- Constraint, index, transaction болон төрөлтэй таарсан ганц дэлгэрэнгүй мөртэй байх арга нэгтгэсэн schema-д батлагдсан; SQL хэрэгжүүлэлт/тест хийгдээгүй.
- `vehicles`, `parts`, `tires`, зураг болон admin profile-ийн [нэгтгэсэн schema](catalog-schema-proposal.md) батлагдсан. Лавлахын хүснэгт/нийтлэг багана [батлагдсан](reference-tables.md); constraint/index-ийн хэрэгжүүлэлтийг нарийвчилна.

Дараагийн хэрэгжүүлэлтээр Drizzle schema болон migration үүссэн; [бодит ажиллагааны зааг](../operations/db-migrations.md). Энэ баталгаа `docs.task.md`-ийн техникийн task-уудыг бүхэлд нь дуусгахгүй.
