# Дугуйн лавлах ба тогтмол сонголтууд

- Огноо: 2026-09-10
- Төлөв: Үндсэн лавлах ба enum/const ангилал батлагдсан; индекс, нэмэлт тэмдэглэгээний арга нээлттэй
- Үндэслэл: Хэрэглэгч 3 DB лавлах, 11 enum/const бүлгийн саналыг баталсан
- Холбоотой баримт: [Дугуйн талбарууд](../features/tire-fields.md), [Дундын лавлахын тойм](README.md#дундын-лавлах), [ADR 0018](../adr/0018-use-tire-reference-data.md)

## Үндсэн DB лавлах

Нийт **3 лавлах: 2 шинэ + 1 дундын**.

| ID | Лавлах | Ашиглах талбар | Шинэ эсвэл дундын |
| --- | --- | --- | --- |
| TL01 | Дугуйн үйлдвэрлэгч / брэнд | T02 | Шинэ; автомашины марк эсвэл сэлбэгийн брэндтэй автоматаар нэгтгэхгүй |
| TL02 | Дугуйн загвар / цуврал | T03 | Шинэ; дугуйн брэндэд харьяалагдана |
| TL03 | Салбар / байршил | T27 | Автомашин, сэлбэгт ашиглаж буй салбарын лавлахтай дундын |

Брэнд -> загвар -> хэмжээтэй бүтээгдэхүүн гэсэн дараалалтай байна. Нэг дугуйн загварыг олон хэмжээтэй бүтээгдэхүүн ашиглаж болно. Дугуйн загвар нь автомашины загварын лавлах биш. Салбарын хуулбар лавлах үүсгэхгүй; өмнө баталсан дундын лавлахын дүрмийг хадгална.

## Enum/const бүлгүүд

2026-09-10-ны дараагийн [нэгтгэсэн schema баталгаагаар](catalog-schema-proposal.md#сэлбэгдугуйн-тогтмол-утгууд) төрөлд онцлог enum утгууд, text + CHECK хадгалалт болон load/speed индексийг text, нэмэлт тэмдэглэгээг tire_markings-д хөтлөх арга батлагдсан. Доорх өмнөх тэмдэглэлийн холбогдох нээлттэй хэсгийг орлоно; used/mixed-size/метр бус хүрээ, seed болон permission matrix нээлттэй хэвээр.

| ID | Бүлэг | Ашиглах талбар |
| --- | --- | --- |
| TE01 | Нөхцөл | T06 |
| TE02 | Хийц | T10 |
| TE03 | Улирал | T12 |
| TE04 | Тээврийн хэрэгслийн зориулалт | T13 |
| TE05 | Замын зориулалт / хээний төрөл | T14 |
| TE06 | Хадаасны төрөл / төлөв | T19 |
| TE07 | Валют | T22 |
| TE08 | Үнэ харуулах хэлбэр | T23 |
| TE09 | Үнийн нэгж | T24 |
| TE10 | Бэлэн байдлын төлөв | T26 |
| TE11 | Нийтлэлийн төлөв | T31 |

Эдгээр **11 бүлгийг** кодын enum/const байдлаар удирдана; admin-аас дурын утга нэмдэг DB лавлах биш. Дундын тогтмолууд `packages/core`-ийн үүрэгт хамаарна. Төрөлд онцлог бүлгүүдийн бүрэн утга, label, TypeScript identifier/хэлбэр, PostgreSQL-д хадгалах арга хараахан тогтоогүй.

2026-09-10: [Нийтлэг бүтээгдэхүүний дүрмээр](../features/product-common-rules.md) TE07 валют (`MNT`), TE08 үнэ харуулах хэлбэр (`show_price`, `inquire`), TE11 нийтлэлийн төлөв (`draft`, `published`, `hidden`, `archived`) нь автомашин/сэлбэгтэй дундын утга, дүрэмтэй болсон. Бусад бүлгийг автоматаар нэгтгэхгүй.

## Лавлахын нийтлэг дүрэм

Admin нэмэх/нэр засах/идэвхгүй болгох, ашиглагдаж байгаа лавлахыг шууд устгахгүй байх болон [идэвхгүй лавлахын өмнөх сонголтыг хадгалах дүрэм](../features/product-common-rules.md) дугуйн бүх үндсэн лавлахад үйлчилнэ. Өмнөх сонголттой бүтээгдэхүүнийг засах/нийтлэхэд заавал солихгүй; шинэ сонголт зөвхөн идэвхтэй байна. Брэнд солигдоход тохирохгүй загварыг цэвэрлэж, хамаарлыг шалгана. Public нэр хэвийн, идэвхгүй тэмдэглэгээ зөвхөн admin-д байна.

## Лавлах болгохгүй талбарууд

- T07 өргөн, T08 харьцаа, T09 обудны диаметр нь тоон утга байна. Шүүлтийн сонголтыг бүртгэлтэй хэмжээнээс гаргаж болно; хэмжээний тусдаа DB лавлах одоогоор батлаагүй.
- T04 SKU, T05 үйлдвэрлэгчийн бүтээгдэхүүний код нь бүтээгдэхүүний кодын талбар байна.
- T18 run-flat эсэх, T32 онцлох эсэх нь boolean шинжтэй; 11 enum/const бүлгийн тоонд ороогүй. Онцлох эсэхийн default `false` нийтлэг дүрмээр батлагдсан. Run-flat тодорхойгүйг худал үгүй утгаар орлуулахгүй; тусгай requiredness/nullable дүрмийг нарийвчилна.

## Дараа шийдэх зүйлс

- T15 ачааллын индекс, T16 хурдны индекс, T17 даацын нэмэлт тэмдэглэгээ, T20 нэмэлт тэмдэглэгээг хэрхэн хөтлөх.
- Дугуйн 33 талбарын үлдсэн онцлог санал, нийтлэг дүрмээс гаднах нийтлэх/public/filter шаардлага.
- Лавлахын хүснэгт/нийтлэг багана/холбоос/нэрийн давхардлын дүрэм [батлагдсан](reference-tables.md). Seed, normalization, constraint/index-ийн хэрэгжүүлэлт болон admin permission matrix нээлттэй; lifecycle нийтлэг дүрмээр батлагдсан.
- TE01–TE06, TE09–TE10 бүлгийн утга/дүрэм; TE07/TE08/TE11 нийтлэг дүрмээр батлагдсан.
- Метр бус хэмжээ, иж бүрдэл, үйлдвэрлэсэн огноо, хуучин дугуйн ширхэг бүрийн нөхцөл болон олон салбарын мэдээлэл.

## Баталгаажуулалтын зааг

2026-09-10-ны лавлах schema баталгаагаар `tire_brands`, `tire_models`, дундын `branches` хүснэгтийн нэр, нийтлэг багана/төрөл, холбоос, нэрийн давхардлын дүрмийг [лавлахын schema баримтад](reference-tables.md) баталсан. Доорх өмнөх ангиллын баталгааг өргөжүүлсэн; код, migration үүсгээгүй.

Үндсэн 3 лавлах, 11 тогтмол бүлэг, тоон утга/код/boolean-ийн зааг батлагдсан. Энэ нь дугуйн бүх талбар, индексийн арга, сэлбэгийн нэмэлт лавлахууд, DB schema, migration, seed эсвэл кодын хэрэгжүүлэлтийг батлаагүй. Tech spec task-ийн төлөв өөрчлөгдөөгүй.

2026-09-10-ны дараагийн баталгаагаар автомашинтай ижил нийтлэг дүрэм дугуйд үйлчилнэ. Үүнд дээрх 3 enum бүлгийн утга, онцлох эсэхийн default болон лавлахын lifecycle орсон; онцлог бүлгүүд нээлттэй хэвээр.
