# Өгөгдлийн сан

Өгөгдлийн бүтэц, холбоос, бүрэн бүтэн байдлын дүрэм болон схемийн өөрчлөлтийг энд баримтжуулна.

## Технологийн сонголт

- Database: **PostgreSQL**
- ORM: **Drizzle ORM**
- Migration: **Drizzle migration workflow**

ORM сонголтыг [ADR 0003](../adr/0003-use-drizzle-orm.md), database болон migration сонголтыг [ADR 0005](../adr/0005-use-postgresql-and-drizzle-migrations.md)-д бүртгэсэн. Яг хувилбарууд, driver, schema-ийн бүтэц, файлын байршил болон migration команд хараахан тогтоогүй.

## Баримтжуулах зүйлс

- Өгөгдлийн загвар, хүснэгтүүдийн холбоосын зураг (ERD)
- Хүснэгт, талбар, өгөгдлийн төрөл, тайлбар
- Анхдагч болон гадаад түлхүүр, заавал бөглөх болон давхцахгүй байх нөхцөл
- Индекс, хайлт болон шүүлтэд шаардлагатай бүтэц
- Схемийн өөрчлөлт (migration), эхлэх өгөгдөл (seed)
- Өгөгдөл хадгалах, устгах болон хувийн мэдээлэлтэй харьцах дүрэм

## Загварчлах үндсэн мэдээлэл

- Автомашин: марк, модель, он, үнэ, төлөв, техникийн үзүүлэлт
- Автомашины зураг: байршил, дараалал, үндсэн зураг
- Компанийн танилцуулга, үйлчилгээ, холбоо барих мэдээлэл

Эдгээр нь шаардлагаас үүдсэн анхны жагсаалт бөгөөд батлагдсан хүснэгтийн схем биш. Мэдээлэл тус бүрийн хадгалалт, schema-ийн байршил болон website/admin-ийн хандалтын заагийг цаашид тодорхойлно.

## Хөтлөх зарчим

Схемийн өөрчлөлт бүрийн зорилго, нөлөөлөх өгөгдөл, шилжүүлэх болон буцаах аргыг тэмдэглэнэ. Бодит нууц үг, холболтын нууц мэдээлэл, хэрэглэгчийн хувийн өгөгдөл оруулахгүй. Нөөцлөх, сэргээх ажиллагааг [operations](../operations/README.md)-д баримтжуулна.
